## 是什么

PanguVerse 是一个**原子编排平台**：先把业务拆成可复用的「原子」步骤，再把这些原子组合成完整的编排流程。使用者不必从零写完整脚本，而是描述要做什么，由平台负责规划、执行与收尾。

## 当前能做什么

Web 控制台目前提供五块能力：

- **概览**：展示平台状态、环境信息（工作区、版本、规划方式）与最近运行。
- **运行**：用自然语言意图或选择场景发起一次编排；也提供演示模式用于快速体验。
- **运行历史**：查看历史运行及其阶段进度，可下载 JUnit 结果、打开 HTML 报告。
- **原子库**：按领域、标签、分类筛选可复用的原子步骤。
- **领域包**：浏览领域包以及每个包内包含的原子。

一次编排按阶段推进：规划 → 校验 → 执行 → 自愈 → 报告（后续还有沉淀与回归）。失败阶段会被标出，可查看原因与报告，而不是静默失败。

## 本机开发调试

上面的线上地址是部署后的控制台。若在本机调试，在 PanguVerse 仓库根目录启动本地服务：

```bash
panguverse serve --port 7788 --no-open
```

然后访问 `http://127.0.0.1:7788/`。控制台的所有数据都来自本地后端的 `api` 接口，后端未启动时页面会直接提示原因。
