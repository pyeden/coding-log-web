# 智能旅行助手

<TravelAssistant />

## 能做什么

- **规划**：目的地、日期、预算、人数、偏好，加上同行人、节奏、忌口、无障碍、交通与住宿预算画像。
- **行程**：逐日天气与穿衣建议、住宿区域、交通提示与缓冲时间；景点、用餐、住宿、交通、休息分类型展示，景点带「室内备选」。
- **今日**：自动定位当天，显示天气/穿衣，下一站与导航、路线提示、住宿区域和紧急入口，天气可刷新。
- **附近推荐**：吃饭 / 住宿 / 交通 / 紧急四类 POI，含距离、评分、人均、推荐理由与导航、外部链接；数据源为静态兜底时会明确标注。
- **打包清单**：按分类勾选，勾选状态保存在本地（按行程区分）。
- **分享与导出**：生成只读分享链接，复制文本行程，下载 `.ics` 日历与 `.json` 数据。
- **反馈**：每个安排可标记「有用/没用」「去了/没去」，用于后续优化推荐。
