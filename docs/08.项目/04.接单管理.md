# 接单管理

<OrderAssistant />

## 能做什么

- **需求管理**：提交项目名称、客户、类别、需求描述、交付物、期望工期与预算参考；保存在当前浏览器，可随时修改基础信息。
- **自动报价**：每次提交按 2026 国内市场人日价、需求复杂度、交付物数量与工期紧迫度计算，给出区间价、建议价、置信度、分阶段明细和市场依据。
- **多轮改价**：范围变化后提交新一轮，系统重新报价，并列出与上一轮的金额差异与原因（交付物、工期、复杂度、类别）。
- **状态流转**：已报价 → 已确认 → 进行中 → 已结单，或取消；状态与报价记录一并保留。

## 报价口径

- 类别基线：全栈 Web 1400、前端 1100、后端 1300、小程序 1200、AI 应用 1800、数据 1200、自动化 1000、设计 900、运维 1000 元/人日。
- 工作量：类别基础人日 + 交付物数量 × 1.5，再乘复杂度系数（0.8–1.6）。
- 加急：期望工期明显短于估算工期时乘 1.12 或 1.25。
- 区间：建议价上下浮动约 12%–15%；报价不按客户预算倒推。

## 后台

后台管理页使用 Django admin + ElementUI：需求与报价的增删改查、报价明细查看、人工调价、市场价目维护。
