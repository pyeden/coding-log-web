# 07 包、模块与依赖

## 本章目标

理解包与模块的区别，能读懂 `go.mod` 与 `go.sum`，设计合理的目录与可见性边界，并掌握依赖升级、vendor 与可复现构建。

## 包与导入

包（package）是编译与可见性的基本单位，一个目录下的所有 `.go` 文件必须属于同一个包。包名通常与目录名一致，但不强制；导入路径由**模块路径 + 目录**决定。

导入时可以使用别名，`_` 表示只执行包的 `init` 而不直接使用，常用于驱动注册（如数据库驱动）。包级变量按依赖顺序初始化，随后执行 `init()`，多个 `init` 按文件名字典序执行。

```go
package main

import (
	"fmt"
	m "math"
)

var initialized = setup()

func setup() string {
	fmt.Println("包级变量初始化")
	return "ready"
}

func init() {
	fmt.Println("init 执行:", initialized)
}

func main() {
	fmt.Println(m.Sqrt(16))
}
```

## 模块

模块（module）是版本化的一组包，由 `go.mod` 定义。模块路径是导入前缀，不一定是真实网址，但应保证全局唯一，常见做法是仓库地址。

```text
example.com/shop/
  go.mod
  main.go
  internal/auth/auth.go
  catalog/catalog.go
```

`go.mod` 记录模块路径、Go 版本与直接依赖；`go.sum` 记录所有模块的校验和，防止下载内容被篡改。两者都应提交。`go mod tidy` 会补齐缺失依赖并移除未使用项。

## internal 与可见性

目录名 `internal` 有特殊含义：只有其父目录为根的子树可以导入它。这是编译器强制的边界，比文档约定可靠。

```go
// Package greet 提供简单的问候文本。
package greet

import "fmt"

// Hello 返回面向 name 的问候语。
func Hello(name string) string {
	return fmt.Sprintf("你好，%s", name)
}

func internalHelper() string { return "internal" }
```

上面的文件是包片段，不是完整程序：`Hello` 首字母大写可被其他包导入，`internalHelper` 仅包内可见。包注释写在 `package` 前，`go doc` 会把它作为包说明。

## 语义化版本与依赖管理

Go 模块使用语义化版本 `vMAJOR.MINOR.PATCH`。主版本号大于 1 时，模块路径必须带 `/v2` 后缀（Go Modules 的规则），否则不同主版本无法共存。升级依赖前先读目标版本的 release notes，主版本跃迁往往包含不兼容变更。

```bash
go get example.com/lib@v1.4.2   # 升级到指定版本
go get example.com/lib@latest   # 升级到最新
go list -m all                  # 查看当前模块图
go mod tidy                     # 整理依赖
go mod vendor                   # 复制依赖到 vendor/
go mod verify                   # 校验缓存
```

默认构建从模块缓存读取依赖，`-mod=vendor` 或存在 `vendor/` 时改用本地副本，适合离线或强审计环境。`go mod graph` 可排查「为什么这个版本被选中」——Go 采用最小版本选择（MVS），最终版本是所有依赖要求的最低版本中的最高者。

## 可复现构建

可复现的核心是：固定 Go 版本、提交 `go.mod`/`go.sum`、锁定依赖、避免构建时联网。CI 中用 `go build -trimpath` 去掉本地路径，配合固定工具链版本，能让不同机器产出接近一致的二进制。

`toolchain` 指令（Go 1.21+）可以声明建议的工具链版本，但不要依赖它替代 CI 的显式版本管理。

## 常见坑

- **包名与目录名不一致导致困惑**：导入路径用目录，代码里用包名，团队应统一。
- **忘记提交 `go.sum`**：CI 可能拉到不同内容，校验失败或行为漂移。
- **在包级变量里做重 IO**：导入即产生副作用，测试和工具会意外触发。
- **循环导入**：Go 直接禁止，需要把共享类型下沉到独立包。
- **随意使用 `replace`**：本地替换提交后会让别人构建失败，除非是团队约定。
