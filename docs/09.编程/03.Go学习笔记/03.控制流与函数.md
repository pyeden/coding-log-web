# 03 控制流与函数

## 本章目标

掌握 Go 仅有的几种控制结构，理解 `defer` 的执行顺序，能熟练使用多返回值、闭包与可变参数，并知道函数值在工程中的常见用法。

## 分支与循环

`if` 的条件不需要括号，但必须有花括号；可以在条件前写一条初始化语句，其作用域仅限该 `if`。`for` 是 Go 唯一的循环关键字：三段式、仅条件、无限循环三种形式覆盖了 `while` 的用法。

`switch` 默认不贯穿（不需要 `break`），一个 `case` 可以列多个值；不带表达式的 `switch` 等价于 `switch true`，适合替代长 `if/else` 链。`fallthrough` 可以强制进入下一个分支，但应少用。

```go
package main

import "fmt"

func classify(n int) string {
	switch {
	case n < 0:
		return "负数"
	case n == 0:
		return "零"
	default:
		return "正数"
	}
}

func main() {
	for i := 0; i < 5; i++ {
		if i == 3 {
			continue
		}
		fmt.Println(i, classify(i-2))
	}

	n := 0
	for n < 3 { // Go 没有 while
		n++
	}
	fmt.Println("n =", n)

	defer fmt.Println("first deferred")
	defer fmt.Println("second deferred")
	fmt.Println("main end")
}
```

`defer` 把调用压栈，函数返回时按**后进先出**执行，因此上面先打印 `main end`，再打印 second、first。`defer` 的参数在注册时求值，循环里大量 `defer` 会推迟资源释放，必要时封装成函数。

`range` 可遍历数组、切片、字符串、映射与通道。遍历通道时会一直阻塞到通道关闭，因此发送方必须记得 `close`；遍历映射的顺序随机，需要稳定顺序时先取键排序。`goto` 虽然存在，但只建议用于跳出多层循环的极少数场景，普通代码用标签加 `break` 更清晰。`break` 默认只跳出最内层循环。

## 多返回值与错误

Go 函数可以返回多个值，最常见的组合是「结果 + error」。调用方必须显式处理错误，这是 Go 错误处理风格的基石（第 06 章展开）。

```go
package main

import (
	"errors"
	"fmt"
)

func divmod(a, b int) (int, int, error) {
	if b == 0 {
		return 0, 0, errors.New("除数不能为零")
	}
	return a / b, a % b, nil
}

func main() {
	q, r, err := divmod(17, 5)
	if err != nil {
		fmt.Println("失败:", err)
		return
	}
	fmt.Println(q, r)
}
```

命名返回值可以在函数体内直接赋值并用裸 `return` 返回，适合短函数；长函数使用命名返回值会降低可读性。公共函数应保持职责单一，参数超过四五个时考虑用配置结构体，避免调用方按位置猜含义。

## 函数值、闭包与可变参数

函数是一等公民，可以赋值、作为参数、作为返回值。闭包捕获外部变量，捕获的是变量本身而非副本。可变参数 `...T` 在函数内表现为 `[]T`，调用时用 `slice...` 展开。

```go
package main

import "fmt"

func sum(nums ...int) int {
	total := 0
	for _, n := range nums {
		total += n
	}
	return total
}

func counter() func() int {
	n := 0
	return func() int {
		n++
		return n
	}
}

func apply(f func(int) int, v int) int {
	return f(v)
}

func main() {
	fmt.Println(sum(1, 2, 3))
	values := []int{4, 5, 6}
	fmt.Println(sum(values...))

	next := counter()
	fmt.Println(next(), next(), next())

	fmt.Println(apply(func(x int) int { return x * x }, 6))
}
```

闭包在并发场景要特别注意共享变量；Go 1.22 起 `for` 循环变量每轮独立（见第 08 章），此前的版本需要用局部变量或参数固定当前值。函数值只能与 `nil` 比较，不能互相比较；需要把「行为」作为映射键时，改用字符串或枚举标识。递归函数必须有明确终止条件，Go 不做尾调用优化，深层递归仍可能耗尽栈。

## 常见坑

- **`if` 后换行写 `{`**：Go 的分号插入规则会导致语法错误，左花括号必须与条件同行。
- **以为 `switch` 会贯穿**：默认不贯穿，需要时显式 `fallthrough`。
- **在循环里 `defer` 关闭文件**：延迟到函数结束才执行，可能耗尽文件描述符。
- **闭包捕获循环变量**：1.22 之前所有闭包可能看到同一个最终值。
- **可变参数传 `nil` 切片**：`sum(nil...)` 合法，函数内得到空切片。
