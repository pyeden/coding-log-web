# 02 语言基础与类型

## 本章目标

掌握变量声明与零值语义，理解常量与 `iota`，分清 Go 的静态类型与显式转换规则，并能正确处理字符串、字节与 Unicode 码点。

## 变量与短声明

`var` 用于显式声明，可以带类型或直接初始化；`:=` 是短变量声明，只能在函数内部使用，类型由右侧推断。包级变量只能用 `var`，不能用 `:=`。

Go 的变量总有**零值**：数值为 `0`，字符串为 `""`，布尔为 `false`，指针、切片、映射、通道、函数、接口为 `nil`。不存在「未初始化」的变量，这消除了大量悬空值问题。

```go
package main

import "fmt"

const (
	StatusOK = iota
	StatusNotFound
	StatusError
)

func main() {
	var name string
	var count int
	var ratio float64
	var ready bool
	fmt.Printf("%q %d %g %t\n", name, count, ratio, ready)

	age := 32
	pi := 3.14159
	fmt.Printf("%T %T\n", age, pi)

	fmt.Println(StatusOK, StatusNotFound, StatusError)
}
```

同一作用域内 `:=` 至少要声明一个新变量，否则编译失败；`age, err := 1, nil` 这种写法常用于复用已有变量。包级变量在 `main` 之前按依赖顺序初始化，因此不要让包级变量依赖命令行参数或环境中的运行时状态。

## 常量与 iota

`const` 声明编译期常量，值必须是常量表达式。`iota` 在每个 `const` 块内从 0 递增，适合定义枚举。需要跳过值时用 `_` 占位；需要字符串枚举时，配合自定义类型与 `String()` 方法比裸字符串更安全。

无类型常量（untyped constant）在赋值时按上下文取类型，`const Pi = 3.14` 既能参与 `float64` 运算，也能赋给 `float32`；一旦显式标注类型，这种灵活性就消失了。整数常量按任意精度计算，只有赋给具体类型时才检查溢出，所以 `const Big = 1 << 62` 可以通过编译。

## 基本类型

- 整数：`int`、`int8/16/32/64`、`uint` 系列、`uintptr`。`int` 的宽度随平台变化，涉及二进制协议或文件格式时要用定宽类型。
- 浮点：`float32`、`float64`；金额计算不要用浮点，改用整数分或定点库。
- 复数：`complex64`、`complex128`。
- 布尔：`bool`，不能与整数互转。
- 字符串：`string`，不可变字节序列，通常存放 UTF-8。
- 字符：`byte` 是 `uint8` 的别名，`rune` 是 `int32` 的别名，表示一个 Unicode 码点。

Go **没有隐式类型转换**。`int` 与 `int64` 是不同类型，必须显式转换；转换可能截断，编译器不会阻止。

```go
package main

import "fmt"

func main() {
	var i int = 300
	b := byte(i) // 截断，只保留低 8 位
	f := float64(i) / 7
	fmt.Println(b, f)
	fmt.Println(int(f))
}
```

## 字符串、字节与 UTF-8

`len(s)` 返回**字节数**，不是字符数。用 `range` 遍历字符串时，每轮解码一个 UTF-8 码点，索引是字节偏移，值类型是 `rune`。需要按字符随机访问时先转 `[]rune`；处理二进制或网络协议时用 `[]byte`。

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func main() {
	text := "Go语言"
	fmt.Println(len(text))                    // 字节数
	fmt.Println(utf8.RuneCountInString(text)) // 字符数

	for i, r := range text {
		fmt.Printf("%d:%c ", i, r)
	}
	fmt.Println()

	bs := []byte(text)
	fmt.Println(bs[0], bs[2])

	rs := []rune(text)
	fmt.Println(len(rs), string(rs[2]))
}
```

字符串拼接用 `+` 在少量场景可读，循环内应使用 `strings.Builder`，避免反复分配。`string` 与 `[]byte` 互转都会复制，热点路径要留意。格式化输出常用 `%v`（默认格式）、`%+v`（带字段名）、`%q`（带引号转义）与 `%#v`（Go 语法表示），调试结构体时尤其有用；动词与参数类型不匹配时，`go vet` 会给出提示。

## 常见坑

- **以为 `len("中文")` 是 2**：实际是 6 个字节。
- **用下标取中文字符**：`s[0]` 得到的是字节，不是字符。
- **混用 `int` 与 `int64`**：编译期直接报错，别指望自动提升。
- **浮点比较相等**：二进制表示有误差，应比较差值阈值。
- **常量溢出**：无类型常量在赋值时才确定类型，超范围会编译失败。
