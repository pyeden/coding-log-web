# 02 语言基础与字符串

## 本章目标

掌握 Python 的词法规则、变量语义和字符串操作，能读懂并写出符合 PEP 8 风格的日常代码。字符串是文本处理的中心，本章会花一半篇幅在它身上。

## 词法与缩进

Python 用缩进表示代码块，标准是 **4 个空格**，禁止空格与 Tab 混用。逻辑行结束不需要分号；一行写多条语句用分号但可读性差。注释用 `#`，三引号字符串放在函数或模块开头即成为 **docstring**（文档字符串），可被 `help()` 读取。

命名规则：标识符由字母、数字、下划线组成，不能数字开头，区分大小写。约定上，变量与函数用 `snake_case`，类用 `PascalCase`，常量用 `UPPER_CASE`。

## 变量与动态类型

Python 变量是**对象的引用**，不是装值的盒子。赋值只改变引用指向，类型属于对象而非变量，所以同一个名字可以先后指向 `int` 和 `str`。这种动态类型带来灵活性，代价是类型错误只在运行时暴露（第 09 章用类型注解弥补）。

```python
x = 42
print(type(x))        # <class 'int'>
x = "四十二"
print(type(x))        # <class 'str'>

a = [1, 2, 3]
b = a                 # 同一个列表对象的两个名字
b.append(4)
print(a)              # [1, 2, 3, 4]
```

需要判断「是不是同一个对象」用 `is`，判断「值是否相等」用 `==`。`is` 只应用于 `None`、`True`、`False` 这类单例。

Python 的真值判断很宽容：`0`、`0.0`、`""`、`[]`、`{}`、`set()`、`None`、`False` 都为假，其余对象默认为真（可通过 `__bool__` 或 `__len__` 自定义）。因此 `if items:` 比 `if len(items) > 0:` 更地道。`and`、`or` 是短路运算符且返回**操作数本身**，所以 `name = user_input or "匿名"` 可以作为默认值写法；链式比较 `0 <= x < 100` 也只求值一次中间项。

## 数字

`int` 是任意精度整数，`float` 是 IEEE-754 双精度，`complex` 表示复数。除法 `/` 永远得到 float，整除用 `//`，取余 `%`，幂 `**`。浮点数存在二进制表示误差，金额计算用 `decimal.Decimal` 或整数分。`bool` 是 `int` 的子类，`True == 1`。

## 字符串

字符串是不可变序列，支持索引、切片与大量方法。切片 `s[start:stop:step]` 左闭右开，省略边界表示到头，负索引从末尾算。所有「修改」字符串的方法都返回新对象，原字符串不变——循环里反复拼接会不断分配内存，这也是第 03 章强调 `join` 的原因。

```python
s = "  Python 学习笔记  "
print(s.strip())                 # 去掉两端空白
print(s.strip().lower())         # python 学习笔记
print(s.strip()[0:6])            # Python
print(s.strip()[::-1])           # 记笔习学 nohtyP
print("a,b,c".split(","))        # ['a', 'b', 'c']
print("-".join(["2026", "10", "27"]))  # 2026-10-27
print("py" in "python")          # True
```

**f-string** 是首选格式化方式，`f"{value!r:>10}"` 中 `!r` 调用 `repr`，冒号后是格式说明符。

```python
name = "三木"
score = 92.5
print(f"{name} 的成绩是 {score:.1f}")
print(f"{name!r} 共 {len(name)} 个字符")
print(f"{1234567:,}")            # 1,234,567
print(f"{0.873:6.1%}")           #  87.3%
```

多行文本用三引号，保留换行与缩进；需要去掉公共缩进时用 `textwrap.dedent`。`strip`、`replace`、`split` 都返回新字符串，原对象不变；需要判断前后缀用 `startswith` / `endswith`，比切片比较更清晰。

## bytes 与 str

`str` 是 Unicode 码点序列，`bytes` 是 0–255 的字节序列，两者不能隐式拼接。网络与文件二进制读写产生 `bytes`，需显式编解码：`"中文".encode("utf-8")` 得到 `b'\xe4\xb8\xad\xe6\x96\x87'`，反向用 `.decode("utf-8")`。编码不匹配会抛 `UnicodeDecodeError`，处理外部数据时要指定 `encoding="utf-8"`，不要依赖系统默认。

## 输入输出

`print()` 默认以空格分隔、换行结尾，可用 `sep`、`end` 改写。`input()` 返回字符串，数字需自行转换并处理非法输入。读写文件见第 08 章的 `pathlib` 与上下文管理器。

```python
raw = " 18 "
age = int(raw.strip())
print("明年", age + 1, sep="：", end="。\n")
```

## 常见坑

- **用 `is` 比较字符串或数字**：结果依赖实现，可能偶然正确。
- **可变对象当默认参数**：见第 03 章。
- **混淆 `str` 与 `bytes`**：从 socket 或文件读到的不是 `str`。
- **拼接大量字符串用 `+`**：循环里应收集到列表再 `"".join()`，复杂度更可控。
- **源码编码**：Python 3 默认 UTF-8，跨平台读取外部文件仍应显式声明编码。
