# 03 数据结构与推导式

## 本章目标

熟悉内置容器的时间复杂度与适用场景，能写出简洁且不踩坑的推导式，理解可变对象的浅拷贝与默认参数陷阱。

## 四种核心容器

- **list**：有序、可变、可重复，尾部追加和索引是 O(1)，头部插入是 O(n)。
- **tuple**：有序、不可变，可哈希，适合当「记录」或字典键。
- **dict**：键值映射，3.7 起保证插入顺序，查找平均 O(1)，键必须可哈希。
- **set**：无序不重复集合，成员判断平均 O(1)，常用于去重与集合运算。

选择顺序通常是：需要键值映射用 dict，需要去重或快速成员判断用 set，需要顺序与可变用 list，需要不可变记录用 tuple 或 `NamedTuple`。判断依据不是「哪个更高级」，而是访问模式：随机下标多就 list，按 key 查就 dict，只判断存在性就 set。容器选错往往不会报错，只会让复杂度悄悄从 O(1) 退化到 O(n)。字典还提供 `setdefault`、`update` 与 `|` 合并（3.9+），写配置合并时比手写循环清晰。

## 切片与解包

切片对 list、tuple、str 都适用，返回新对象（浅拷贝）。`a[::-1]` 反转，`a[1:5:2]` 步长切片。切片赋值可以替换或删除片段，且右侧长度不必与左侧一致，这也是它与「按下标赋值」最大的区别。

序列解包要求两侧数量一致，`*rest` 可收集剩余元素；`a, b = b, a` 直接交换。函数调用时 `*args` 拆位置参数、`**kwargs` 拆关键字参数。带星号的名字只能出现一次，且收集结果总是 list。

```python
nums = [0, 1, 2, 3, 4, 5]
print(nums[1:4])       # [1, 2, 3]
print(nums[-2:])       # [4, 5]
print(nums[::2])       # [0, 2, 4]

nums[1:3] = ["a", "b", "c"]   # 长度可变
print(nums)                    # [0, 'a', 'b', 'c', 3, 4, 5]

first, *middle, last = [1, 2, 3, 4, 5]
print(first, middle, last)      # 1 [2, 3, 4] 5

pairs = [("b", 2), ("a", 1)]
print(dict(pairs))              # {'b': 2, 'a': 1}
```

## 排序与 key

`sorted()` 返回新列表，`list.sort()` 原地排序，二者都稳定。`key` 接收一个函数，返回值参与比较；需要多关键字时返回元组。

```python
rows = [("alice", 90), ("bob", 90), ("carol", 85)]
print(sorted(rows, key=lambda r: (-r[1], r[0])))
# [('alice', 90), ('bob', 90), ('carol', 85)]
```

不要用 `cmp` 风格的两值比较函数，Python 3 已移除 `cmp` 参数；复杂比较用 `functools.cmp_to_key`。

## 推导式与生成器表达式

列表、字典、集合推导式是「用表达式构造容器」的语法糖，比手写循环更快也更清晰。生成器表达式用圆括号，惰性求值，适合大数据流。

```python
squares = [x * x for x in range(6) if x % 2 == 0]
print(squares)                       # [0, 4, 16]

lengths = {w: len(w) for w in ["py", "rust", "go"]}
print(lengths)                       # {'py': 2, 'rust': 4, 'go': 2}

matrix = [[1, 2], [3, 4]]
flat = [n for row in matrix for n in row]
print(flat)                          # [1, 2, 3, 4]

total = sum(x * x for x in range(1_000_000))   # 不建中间列表
print(total)
```

嵌套推导式的顺序与嵌套 for 循环一致：先写外层。可读性优先，超过两层嵌套就该改回普通循环。

## 浅拷贝与可变默认值

`b = a` 只是别名；`a.copy()`、`a[:]`、`list(a)` 是**浅拷贝**，内层可变对象仍共享。深拷贝用 `copy.deepcopy`，但先问自己是否真的需要。

```python
import copy

grid = [[0, 0], [0, 0]]
shallow = grid.copy()
shallow[0][0] = 9
print(grid)            # [[9, 0], [0, 0]]：内层共享

deep = copy.deepcopy(grid)
deep[1][1] = 7
print(grid)            # 不受影响
```

同样的共享语义导致了 Python 最经典的陷阱：默认参数只在函数定义时求值一次，于是可变默认值成了跨调用共享的「全局缓存」。下面第一段是错误示范，第二段是正确写法——默认 `None`，函数内部再创建。

```python
def append_bad(item, bucket=[]):       # 错误示范
    bucket.append(item)
    return bucket

print(append_bad(1))   # [1]
print(append_bad(2))   # [1, 2]，不是 [2]

def append_item(item, bucket=None):    # 正确写法
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket

print(append_item(1), append_item(2))  # [1] [2]
```

## 常见坑

- **边遍历边修改**：遍历 list 时删除元素会跳过项，改为遍历副本或倒序遍历，或构建新列表。
- **用 list 做成员判断**：`x in big_list` 是 O(n)，热点路径换 set。
- **dict 键用可变对象**：list 不可哈希，会直接 `TypeError`。
- **依赖 set 的顺序**：输出顺序不保证，需要稳定顺序就排序。
- **误以为 `sort()` 有返回值**：原地排序返回 `None`，`x = a.sort()` 会让 `x` 变成 `None`。
- **用 `dict[key]` 取可能缺失的键**：不存在时抛 `KeyError`，可预期缺失用 `dict.get(key, default)`。
