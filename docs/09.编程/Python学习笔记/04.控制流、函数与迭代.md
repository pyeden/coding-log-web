# 04 控制流、函数与迭代

## 本章目标

写清楚分支与循环，理解 `for` 背后的迭代协议，掌握函数参数的各种形态、作用域规则以及装饰器的基本原理。

## 分支与循环

`if / elif / else` 按顺序短路求值，条件表达式 `x if cond else y` 适合简单二选一。`for` 遍历任何可迭代对象，`while` 依赖条件；`break` 跳出当前循环，`continue` 跳过本轮。两个循环都支持少见的 `else` 子句：**循环正常结束（没有被 break）时执行**，常用于「查找失败」分支。

```python
targets = [3, 7, 11]
for n in targets:
    if n % 2 == 0:
        print(f"找到偶数 {n}")
        break
else:
    print("没有偶数")      # 会执行
```

`range(stop)`、`range(start, stop)`、`range(start, stop, step)` 生成等差数列，惰性且省内存。需要索引时用 `enumerate(iterable, start=0)`，需要并行遍历用 `zip`，二者都比手写下标清晰。3.8+ 的海象运算符 `:=` 可以在条件里赋值，适合「读取后立即判断」的场景：`while (line := fh.readline()):`。

## match 语句（3.10+）

`match` 是结构化模式匹配，不是简单的 switch：它能解构序列、映射与类实例，并绑定变量。`case _` 是通配分支。

```python
def describe(command):
    match command.split():
        case ["go", direction]:
            return f"向 {direction} 前进"
        case ["pick", *items] if items:
            return f"拾取 {len(items)} 件物品"
        case _:
            return "未知指令"

print(describe("go north"))
print(describe("pick apple coin"))
```

注意模式中的名字是**捕获**而非比较，比较字面量要写常量或用守卫（`if`）。`match` 需要 Python 3.10 及以上，低版本请用 `if/elif`。

## 函数参数

位置参数、关键字参数、默认参数、可变位置参数 `*args`、可变关键字参数 `**kwargs` 可以组合，顺序固定为：普通参数 → 默认参数 → `*args` → 仅关键字参数 → `**kwargs`。`/` 之前的参数只能按位置传，`*` 之后的只能按关键字传（仅限关键字参数）。把参数设计成仅关键字，可以在不破坏调用方的前提下后续添加新参数。

```python
def fetch(url, /, timeout=5, *, retries=2, **headers):
    return {"url": url, "timeout": timeout, "retries": retries, "headers": headers}

print(fetch("https://example.com", 3, retries=1, accept="text/html"))
```

默认参数在**定义时**求值一次，可变默认值是经典错误（见第 03 章）。参数传递采用「传对象引用」：函数内修改可变对象会影响调用方，重新赋值则不会。

## 作用域、闭包与 lambda

Python 采用 LEGB 规则查找名字：Local → Enclosing → Global → Builtin。函数内赋值会创建局部变量，要修改外层变量需 `nonlocal`，修改模块级变量需 `global`——后者应尽量避免。

闭包是「函数 + 引用的外层变量」。内层函数记住的是变量本身而非当时的值，循环中创建闭包要小心延迟绑定。

```python
def make_counter():
    count = 0

    def step():
        nonlocal count
        count += 1
        return count

    return step

counter = make_counter()
print(counter(), counter(), counter())   # 1 2 3
```

`lambda` 只能包含单个表达式，适合作为 `key`、`sorted`、`map` 的短回调；有分支或需要文档时用 `def`。

## 装饰器基础

装饰器是「接收函数、返回函数」的可调用对象，`@decorator` 等价于 `func = decorator(func)`。它依赖函数是一等对象与闭包。写装饰器时用 `functools.wraps` 保留原函数的名称与文档。

```python
import functools
import time

def timed(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return func(*args, **kwargs)
        finally:
            elapsed = time.perf_counter() - start
            print(f"{func.__name__} 用时 {elapsed:.4f}s")
    return wrapper

@timed
def slow_sum(n):
    return sum(range(n))

print(slow_sum(100_000))
```

带参数的装饰器需要多一层函数；生产代码优先用标准库的 `functools.lru_cache`、`contextlib.contextmanager`，而不是重复造轮子。

## 迭代协议

`for` 先调用 `iter(obj)` 得到迭代器，再反复 `next()` 直到 `StopIteration`。实现 `__iter__` 与 `__next__` 即可自定义迭代；生成器函数用 `yield` 自动实现这套协议，并天然支持惰性求值。

## 常见坑

- **在遍历中修改容器**：结果不可预期，先复制或构建新列表。
- **`global` 滥用**：状态难追踪，优先用参数与返回值。
- **闭包捕获循环变量**：用默认参数 `lambda i=i: ...` 或 `functools.partial` 固定当前值。
- **忘记 `return`**：函数默认返回 `None`。
- **装饰器丢失元信息**：不加 `functools.wraps` 会影响日志、文档与调试。
