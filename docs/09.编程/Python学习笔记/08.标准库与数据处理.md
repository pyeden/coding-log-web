# 08 标准库与数据处理

## 本章目标

熟悉「不用装包就能解决八成日常问题」的标准库模块：路径、JSON、时间、正则、容器工具、命令行与 SQLite。重点不是背 API，而是知道问题该找哪个模块。

## pathlib 与文件读写

`pathlib.Path` 用对象表达路径，`/` 拼接，跨平台且可读。读写文本务必显式指定 `encoding="utf-8"`；用 `with` 语句确保文件关闭（上下文管理器在异常时也会释放资源）。二进制用 `"rb"/"wb"`。

```python
import json
from pathlib import Path

data_dir = Path("data")
data_dir.mkdir(exist_ok=True)
path = data_dir / "config.json"

payload = {"name": "三木", "tags": ["python", "web"]}
path.write_text(json.dumps(payload, ensure_ascii=False, indent=2), encoding="utf-8")

with path.open(encoding="utf-8") as fh:
    loaded = json.load(fh)

print(loaded["tags"])
for item in sorted(data_dir.iterdir()):
    print(item.name, item.stat().st_size)
```

`json.dumps` 默认 `ensure_ascii=True`，中文会变成 `\uXXXX`，对外输出时设为 `False`。`json.loads` 解析失败抛 `json.JSONDecodeError`，处理外部数据要捕获。写文件时建议「先写临时文件再 rename」，避免进程中断留下半个 JSON；`pathlib` 的 `write_text` 简单直接，但不具备原子性。读取大文件不要 `read_text()` 一次性载入内存，按行迭代或分块处理；`open(..., newline="")` 可以关闭换行转换，处理 CSV 时尤其重要。

## 时间与时区

`datetime` 分「朴素」与「感知」两类。没有 `tzinfo` 的是朴素时间，只能表示本地墙上时间，跨时区计算必然出错。Python 3.9+ 标准库提供 `zoneinfo`，直接使用 IANA 时区数据库：

```python
from datetime import datetime, timedelta
from zoneinfo import ZoneInfo

sh = ZoneInfo("Asia/Shanghai")
start = datetime(2026, 10, 27, 9, 0, tzinfo=sh)
end = start + timedelta(hours=8)
print(end.isoformat())                 # 2026-10-27T17:00:00+08:00
print(end.astimezone(ZoneInfo("UTC"))) # 2026-10-27 09:00:00+00:00
print(end.timestamp())
```

时间戳是 UTC 秒数，是存储与传输的首选；展示时再转本地时区。格式化用 `strftime`，解析用 `datetime.strptime` 或 3.11+ 的 `datetime.fromisoformat` 增强解析。不要用 `datetime.utcnow()` 获取当前时间，它返回朴素时间且已被弃用，改用 `datetime.now(ZoneInfo("UTC"))`。

## 正则

`re` 适合结构化文本抽取。预编译常用模式，使用原始字符串避免转义混乱。`findall` 返回字符串或元组，`finditer` 返回匹配对象（可拿到位置），命名分组提高可读性。

```python
import re

pattern = re.compile(r"(?P<date>\d{4}-\d{2}-\d{2})\s+(?P<level>INFO|ERROR)")
text = "2026-10-27 INFO 启动成功\n2026-10-28 ERROR 连接失败"
for m in pattern.finditer(text):
    print(m.group("date"), m.group("level"))
```

正则应避免灾难性回溯：少用嵌套量词（如 `(a+)+`），长文本优先用字符串方法或解析库。

## 容器与迭代工具

`collections` 提供 `Counter`（计数）、`defaultdict`（缺省值）、`deque`（双端队列）、`namedtuple`。`itertools` 提供惰性组合工具：`chain` 串联、`islice` 切片、`groupby` 分组（需先按 key 排序）、`product` 笛卡尔积。`functools` 的 `lru_cache` 做记忆化，`partial` 固定部分参数。

```python
from collections import Counter, defaultdict
from functools import lru_cache
from itertools import chain, islice

words = ["py", "go", "py", "rust"]
print(Counter(words).most_common(2))      # [('py', 2), ('go', 1)]

groups = defaultdict(list)
for word in words:
    groups[len(word)].append(word)
print(dict(groups))

print(list(islice(chain(range(3), range(10, 13)), 4)))

@lru_cache(maxsize=None)
def fib(n: int) -> int:
    return n if n < 2 else fib(n - 1) + fib(n - 2)

print(fib(50))
```

## 命令行与数据持久化

`argparse` 生成帮助、校验类型并返回命名空间；`sqlite3` 是零配置的单文件数据库，适合本地工具与小型服务。SQL 参数必须用占位符 `?` 传递，禁止字符串拼接，避免注入。

```python
import argparse
import sqlite3

parser = argparse.ArgumentParser(description="导入记录")
parser.add_argument("--db", default=":memory:")
parser.add_argument("--limit", type=int, default=10)
args = parser.parse_args([])

conn = sqlite3.connect(args.db)
conn.execute("CREATE TABLE IF NOT EXISTS note (id INTEGER PRIMARY KEY, body TEXT)")
conn.execute("INSERT INTO note (body) VALUES (?)", ("第一条笔记",))
conn.commit()

for row in conn.execute("SELECT id, body FROM note LIMIT ?", (args.limit,)):
    print(row)
conn.close()
```

`csv` 模块处理逗号分隔文件时用 `csv.reader` / `DictReader`，不要手写 `split(",")`——引号、换行、转义都会出错。写 CSV 时用 `newline=""` 打开文件，否则 Windows 上会多出空行。

需要调用外部命令时用 `subprocess.run`，传列表而不是字符串，避免 shell 注入；`check=True` 让非零退出码直接抛 `CalledProcessError`，`capture_output=True` 收集输出。不要用 `os.system`，它无法可靠地拿到输出与退出码。

## 常见坑

- **不写 encoding**：在 Windows 或容器里默认编码可能不是 UTF-8。
- **朴素时间参与计算**：跨时区、夏令时会静默出错。
- **`json.dump` 写入非序列化对象**：`datetime`、`set` 需要自定义 `default`。
- **`groupby` 未排序**：相同 key 不相邻就会被拆成多组。
- **SQLite 多线程共享连接**：默认禁止跨线程使用，按线程创建连接。
- **`os.path` 与 `pathlib` 混写**：同一项目统一一种风格，路径拼接优先用 `/`。
