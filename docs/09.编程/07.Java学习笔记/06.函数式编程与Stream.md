# 06 函数式编程与Stream

## 本章目标

掌握 lambda 表达式与函数式接口的对应关系、四种方法引用的写法、Stream 管道的惰性求值，以及 `Optional` 的正确用法。目标是写出清晰的数据转换代码，而不是把循环换成更长的链式调用。

## 核心概念

**函数式接口**（functional interface）是只有一个抽象方法的接口，`@FunctionalInterface` 注解让编译器校验这一点。`java.util.function` 提供了最常用的几个：`Function<T,R>`（变换）、`Predicate<T>`（判断）、`Consumer<T>`（消费）、`Supplier<T>`（提供）、`UnaryOperator<T>`/`BinaryOperator<T>`（同类型运算）、`BiFunction<T,U,R>`（双参变换）。

lambda 的本质是函数式接口的实例，它**没有引入新类型**，因此不能赋给 `Object` 之外的任意类型，也不能直接序列化。lambda 捕获局部变量时要求变量**事实不可变**（effectively final），捕获的是值而非引用。

方法引用（method reference）是 lambda 的语法糖，共四种：静态方法 `Type::staticMethod`、特定对象的实例方法 `obj::method`、任意对象的实例方法 `Type::method`、构造器 `Type::new`。

**Stream** 是「描述计算」而非「存储数据」的视图，它不改变源集合。管道由源、若干**中间操作**（intermediate operation，返回 Stream，惰性）、一个**终端操作**（terminal operation，触发执行）组成。没有终端操作时，中间操作一次都不会执行——这是排查「为什么没打印」的第一原则。

中间操作分**无状态**（`map`、`filter`）与**有状态**（`sorted`、`distinct`、`limit`），后者需要缓冲全部或部分元素。`parallelStream` 只在大数据量、纯 CPU 计算、无共享可变状态时可能更快；对小集合或含 IO 的场景几乎总是更慢，默认用串行流。

`Optional<T>` 用来表达「可能没有值」的返回值，而不是字段或参数类型。它提供 `map`/`flatMap`/`filter`/`orElse`/`orElseThrow`，避免层层 `null` 判断；但不要用 `optional.get()` 替代 `null` 检查。

Stream 与循环不是替代关系。需要 `break`、需要修改多个外部变量、或逻辑包含复杂控制流时，普通循环更清晰；Stream 的优势在于声明式描述数据变换，让读代码的人先看到意图而不是下标。

短路操作（short-circuiting）包括 `anyMatch`、`findFirst`、`limit`，满足条件即停止，因此可以处理无限流（`Stream.iterate`）。与之相对，`sorted`、`distinct`、`collect` 必须看到全部元素才能给出结果。

`Collectors` 的高频组合有：`joining`、`groupingBy` 配 `counting` 或 `summingInt`、`partitioningBy`（按布尔分组）、`teeing`（Java 12，一次遍历产出两个结果）。`peek` 只用于调试，它在管道中不保证被执行，不能承载业务副作用。

惰性求值意味着中间操作的顺序会影响性能：先 `filter` 再 `map` 可以少变换元素，反过来则多做无用功。另外 `Stream<Integer>` 的每个元素都会装箱，数值密集计算应改用 `IntStream`、`LongStream` 及其 `sum`、`average`。还要记住流只能被消费一次，重复使用会抛 `IllegalStateException`。

## 代码示例

自定义函数式接口 + 方法引用 + lambda 排序：

```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.function.Function;

public class LambdaDemo {
    @FunctionalInterface
    interface Formatter<T> {
        String format(T value);
    }

    record User(String name, int age) {}

    public static void main(String[] args) {
        Formatter<Integer> hex = v -> "0x" + Integer.toHexString(v);
        System.out.println(hex.format(255));

        Function<String, Integer> length = String::length;      // 任意对象实例方法
        System.out.println(length.apply("java"));

        List<User> users = new ArrayList<>(List.of(
                new User("Chen", 31), new User("Ada", 24), new User("Bob", 45)));
        users.sort(Comparator.comparingInt(User::age).reversed());   // 方法引用作 key
        users.forEach(u -> System.out.println(u.name() + " " + u.age()));

        Runnable hello = () -> System.out.println("hello");   // Runnable 也是函数式接口
        hello.run();
    }
}
```

Stream 管道：过滤、变换、分组、聚合一次完成：

```java
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

public class StreamDemo {
    record Order(String customer, String sku, int amountCents) {}

    public static void main(String[] args) {
        List<Order> orders = List.of(
                new Order("chen", "A-1", 1200),
                new Order("ada", "B-2", 800),
                new Order("chen", "C-3", 2500));

        List<String> bigSkus = orders.stream()
                .filter(o -> o.amountCents() >= 1000)     // 中间操作，惰性
                .map(Order::sku)
                .sorted()
                .collect(Collectors.toList());            // 终端操作，触发执行
        System.out.println(bigSkus);

        Map<String, Integer> totalByCustomer = orders.stream()
                .collect(Collectors.groupingBy(
                        Order::customer,
                        Collectors.summingInt(Order::amountCents)));
        System.out.println(totalByCustomer);

        int total = orders.stream().mapToInt(Order::amountCents).sum();
        System.out.println("总额(分) = " + total);
    }
}
```

`mapToInt` 返回 `IntStream`，避免装箱开销，并提供 `sum`/`average`/`summaryStatistics`。

`Optional` 串起可能为空的查询链：

```java
import java.util.List;
import java.util.Optional;

public class OptionalDemo {
    record User(String name, String email) {}

    static Optional<User> find(List<User> users, String name) {
        return users.stream().filter(u -> u.name().equals(name)).findFirst();
    }

    public static void main(String[] args) {
        List<User> users = List.of(new User("chen", "chen@example.com"));

        String domain = find(users, "chen")
                .map(User::email)
                .filter(e -> e.contains("@"))
                .map(e -> e.substring(e.indexOf('@') + 1))
                .orElse("unknown");
        System.out.println(domain);

        String missing = find(users, "nobody")
                .map(User::email)
                .orElseThrow(() -> new IllegalStateException("用户不存在"));
    }
}
```

`orElseThrow` 无参版本（Java 10）抛 `NoSuchElementException`；带 `Supplier` 的版本可自定义异常类型。

## 常见坑

- **忘记终端操作**：`stream().map(...)` 不执行任何逻辑，必须接 `collect`/`forEach`/`count`。
- **在流中修改源集合**：抛 `ConcurrentModificationException`，需要过滤时用 `removeIf` 而不是先流后删。
- **lambda 里改外部变量**：编译报错「local variables referenced from a lambda expression must be final or effectively final」，应改用归约或容器。
- **无脑 `parallelStream`**：小集合反而更慢，且共享 `ArrayList` 追加会破坏线程安全。
- **`Collectors.toMap` 键重复**：未提供合并函数时抛 `IllegalStateException`。
- **`Optional` 当字段或参数**：既不可序列化也不省内存，只在返回类型上表达「可能缺失」。
