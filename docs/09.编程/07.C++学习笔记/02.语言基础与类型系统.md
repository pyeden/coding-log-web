# 02 语言基础与类型系统

## 本章目标

建立对 C++ 类型系统的准确直觉：知道一个类型占多少字节、什么时候发生隐式转换、`auto` 推导出什么、`const` 到底修饰谁。学完本章，你应该能看懂绝大多数类型声明，并写出不依赖未定义行为的转换代码。

## 核心概念

对象（object）是一块具名或匿名的存储区域，具有类型与生命周期；值类别（value category）区分左值与右值，决定能否取地址与绑定引用；类型推导（type deduction）由 `auto` 与模板实参推导共享规则；隐式转换（implicit conversion）在赋值、传参、比较时自动发生，是多数类型缺陷的来源。

## 内置类型与 sizeof

C++ 的内置类型（fundamental types）包括布尔、字符、整数与浮点。标准只规定了相对大小与最小范围，例如 `1 == sizeof(char) <= sizeof(short) <= sizeof(int) <= sizeof(long)`，具体字节数依赖平台（data model）。字符类型有 `char`、`signed char`、`unsigned char` 三种，`char` 是否有符号由实现决定，不要把它当小整数做算术。要精确宽度就用 `<cstdint>` 的 `std::int32_t`、`std::uint64_t`；要查范围用 `std::numeric_limits`，不要硬编码 `2147483647`。

```cpp
#include <cstddef>
#include <iostream>
#include <limits>

int main() {
    std::cout << "char " << sizeof(char) << '\n'
              << "int " << sizeof(int) << '\n'
              << "double " << sizeof(double) << '\n'
              << "pointer " << sizeof(void*) << '\n';
    std::cout << std::numeric_limits<int>::min() << ' '
              << std::numeric_limits<int>::max() << '\n';
}
```

注意 `sizeof` 返回 `std::size_t`，是无符号类型；把它和有符号整数比较会产生隐式转换，这是常见的告警来源。

## auto、decltype 与 constexpr

`auto` 使用模板实参推导规则，**会丢弃顶层 `const` 与引用**；需要保留就写 `const auto&` 或 `auto&`。`decltype` 则保留表达式的完整类型（含引用），常用于泛型代码中转发返回值类型。`constexpr` 表示「可以在编译期求值」，C++17 允许 `constexpr` 函数包含循环与局部变量，这让编译期计算真正实用。C++20 新增 `consteval`（强制编译期求值）与 `constinit`，C++17 示例不应依赖它们。

```cpp
#include <iostream>
#include <type_traits>
#include <vector>

constexpr int fib(int n) {
    return n < 2 ? n : fib(n - 1) + fib(n - 2);
}

int main() {
    auto i = 42;              // int
    const auto& r = i;        // const int&
    decltype(i) j = 7;        // int
    static_assert(std::is_same_v<decltype(i), int>);
    static_assert(fib(10) == 55);

    std::vector<int> xs{1, 2, 3};
    for (auto& x : xs) { x *= 2; }
    std::cout << i << ' ' << r << ' ' << j << ' ' << xs[2] << '\n';
}
```

## 引用、指针与左右值

引用（reference）是已有对象的别名，必须初始化且不能重新绑定；指针（pointer）本身是对象，可以为空、可以改变指向。函数参数用 `const T&` 传递只读大对象，用 `T&` 表达输出参数，用 `T*` 表达「可能为空」。左值（lvalue）有稳定地址，右值（rvalue）是临时值；`std::move` 只是把表达式转成右值引用，本身不移动任何东西。

C++17 还提供 `std::byte`，用于表达「原始字节」而非字符，避免把二进制数据塞进 `char` 带来的符号性歧义。它只支持位运算，需要数值时必须显式转换，这让接口意图更清楚。

## 类型转换

C++ 有五种显式转换：`static_cast`（相关类型间的合理转换）、`dynamic_cast`（多态类型的安全向下转换）、`const_cast`（去 const，慎用）、`reinterpret_cast`（重新解释位模式，几乎总是错的）、以及 C 风格转换（`(T)x`，语义模糊，应避免）。隐式转换中最危险的是窄化（narrowing），例如 `double` 转 `int` 会截断小数；C++17 的列表初始化 `int x{3.9};` 会直接编译报错，这是好事。

```cpp
#include <iostream>
#include <string>
#include <string_view>

void print(std::string_view sv) { std::cout << sv << '\n'; }

int main() {
    int a = 1, b = 2;
    int& ref = a;
    int* ptr = &b;
    ref = 10;
    *ptr = 20;

    double d = 3.9;
    int truncated = static_cast<int>(d);   // 明确表达截断意图

    const std::string owned = "hello";
    print(owned);        // string_view 不拥有内存，仅观察
    print("literal");    // 无堆分配

    std::cout << a << ' ' << b << ' ' << truncated << '\n';
}
```

`std::string_view` 是 C++17 引入的只读视图，构造开销极小，适合函数参数；但它不拥有字符内存，不能返回指向局部字符串的 `string_view`，否则会悬空。

## 命名空间

命名空间（namespace）用于避免名字冲突。头文件里绝不要写 `using namespace std;`，它会把大量名字注入所有包含者；源文件中可以局部使用 `using std::cout;`。C++17 允许嵌套命名空间简写 `namespace a::b {}`。

```cpp
#include <iostream>

namespace math {
constexpr double pi = 3.141592653589793;
double area(double r) { return pi * r * r; }
}  // namespace math

int main() {
    using math::area;   // 只引入需要的名字
    std::cout << area(2.0) << '\n';
}
```

## 常见坑 / 最佳实践

- 不要假设 `int` 是 4 字节；需要固定宽度用 `<cstdint>`。
- 有符号与无符号混用会产生意外的大数，循环下标优先用 `std::size_t` 或范围 for。
- `auto` 会丢掉引用和顶层 `const`，需要时显式写 `const auto&`。
- 优先列表初始化 `{}`，它能阻止窄化转换。
- 不要把 `string_view` 指向临时字符串；接口边界上明确「谁拥有内存」。
- 用 `constexpr` 替代宏做常量，保留类型与作用域。
