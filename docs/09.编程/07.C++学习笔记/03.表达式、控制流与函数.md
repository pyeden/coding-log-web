# 03 表达式、控制流与函数

## 本章目标

掌握表达式求值规则与常用控制流结构，能写出意图清晰的函数与 lambda。学完本章，你应该能解释「为什么这行代码的结果依赖编译器」，并知道何时用重载、何时用默认参数、何时该把捕获列表写清楚。

## 核心概念

表达式（expression）由运算符与操作数组成并产生值；求值顺序（evaluation order）规定副作用发生的先后；重载决议（overload resolution）在候选函数中按转换序列排序；闭包（closure）是 lambda 捕获环境后生成的函数对象，捕获方式决定其生命周期与可拷贝性。

## 运算符与求值顺序

C++ 的运算符有优先级与结合性，但**操作数的求值顺序**在 C++17 之前大量未指定。C++17 收紧了部分规则（例如 `a = b` 中先求 `b` 再求 `a`，`<<` 的左操作数先于右操作数），但 `f(i++, i++)` 这类写法依然是未定义行为。原则很简单：一个表达式里不要对同一对象做多次无序列的修改。短路求值（short-circuit）则是有保证的：`&&` 左侧为假时右侧不执行，`||` 左侧为真时右侧不执行，可以用它做空指针保护。

## 条件与循环

`if` / `switch` / `for` / `while` / `do-while` 与 C 家族其他语言类似，但有几处 C++ 特有约定：

- `switch` 的条件必须是整型或枚举，`case` 标签必须是常量表达式；忘记 `break` 会贯穿（fallthrough），C++17 可用 `[[fallthrough]]` 明确表达意图。
- 优先使用 `enum class`，它不会隐式转成整数，避免不同枚举互相比较。
- 范围 for（range-based for）遍历任何提供 `begin`/`end` 的对象，遍历时若需修改元素要写 `auto&`。
- C++17 的 `if constexpr` 在编译期选择分支，未选中的分支不会被实例化，是模板编程的重要工具。

```cpp
#include <iostream>
#include <string>
#include <type_traits>
#include <vector>

template <typename T>
std::string describe(const T&) {
    if constexpr (std::is_integral_v<T>) {
        return "整数";
    } else if constexpr (std::is_floating_point_v<T>) {
        return "浮点数";
    } else {
        return "其他";
    }
}

int main() {
    std::vector<int> xs{1, 2, 3};
    for (const auto& x : xs) { std::cout << describe(x) << ' '; }
    std::cout << describe(1.5) << '\n';
}
```

注意 `if constexpr` 的分支仍然要求语法正确，只是不参与实例化；这与预处理宏有本质区别。

## 函数：重载、默认参数与 inline

函数重载（overload）依据参数个数与类型选择版本，**返回类型不参与重载决议**。默认参数（default argument）只能从右向左连续给出，且不要在虚函数里改默认值——调用时按静态类型取默认值，容易与动态绑定结果不一致。`inline` 的现代含义是「允许在多个翻译单元重复定义」，是否真正内联由优化器决定，不要把它当性能开关。

```cpp
#include <iostream>
#include <string>

enum class Color { Red, Green, Blue };

std::string name(Color c) {
    switch (c) {
        case Color::Red: return "red";
        case Color::Green: return "green";
        case Color::Blue: return "blue";
    }
    return "unknown";
}

int add(int a, int b = 1) { return a + b; }
double add(double a, double b) { return a + b; }

int main() {
    std::cout << add(1) << ' ' << add(1.0, 2.0) << ' '
              << name(Color::Green) << '\n';
}
```

## Lambda 与 std::function

lambda 是编译器生成的闭包类型，`[capture](params) -> ret { body }`。捕获列表决定如何访问外部变量：`[=]` 按值、`[&]` 按引用、`[x]` 只按值捕获 `x`、`[&x]` 只按引用捕获 `x`。按引用捕获的 lambda 不能在持有它的对象生命周期之外使用，异步回调里按引用捕获局部变量是典型悬空来源。`mutable` 允许修改按值捕获的副本。

`std::function` 是类型擦除的可调用对象容器，能存函数指针、lambda、绑定表达式，代价是可能的堆分配与间接调用。泛型场景优先用模板参数或 `auto`，只在需要「运行时多态回调」时用 `std::function`。

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <vector>

int main() {
    int threshold = 2;
    auto above = [threshold](int v) { return v > threshold; };  // 按值捕获
    std::vector<int> xs{1, 2, 3, 4};
    std::cout << std::count_if(xs.begin(), xs.end(), above) << '\n';

    std::function<int(int)> twice = [](int v) { return v * 2; };
    std::cout << twice(21) << '\n';
}
```

## 循环写法与边界

下标循环适合需要索引的场景，范围 for 适合遍历全部元素。注意 `std::vector::size()` 返回无符号类型，倒序循环写成 `for (int i = n - 1; i >= 0; --i)` 在 `n == 0` 时会下溢；更稳妥的写法是用迭代器或 `std::size_t` 配合 `i > 0` 判断。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> xs{10, 20, 30};
    for (std::size_t i = 0; i < xs.size(); ++i) { std::cout << xs[i] << ' '; }

    int n = 3;
    while (n-- > 0) { std::cout << n << ' '; }
    std::cout << '\n';
}
```

## 常见坑 / 最佳实践

- 不在同一表达式里多次修改同一对象，避免未定义行为。
- `switch` 覆盖所有枚举值，仍保留兜底 `return`，让编译器不报「可能无返回值」。
- 默认参数只写在声明处，且不要在虚函数中依赖默认参数的动态行为。
- lambda 捕获尽量显式，异步场景按值捕获或使用 `shared_ptr` 延长生命周期。
- 不要返回捕获了局部变量的 lambda。
- 函数职责单一，参数超过四五个时考虑用结构体聚合。
