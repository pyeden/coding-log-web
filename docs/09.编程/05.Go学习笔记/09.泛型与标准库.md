# 09 泛型与标准库

## 本章目标

掌握 Go 泛型的类型参数与约束写法，知道什么时候值得用泛型，并熟悉 `strings`、`strconv`、`time`、`encoding/json`、`net/http` 等高频标准库。

## 类型参数与约束

泛型（generics）从 Go 1.18 开始提供。函数可以声明类型参数，用方括号写在函数名后；约束（constraint）描述类型参数允许的底层类型与方法集合。

`any` 等价于 `interface{}`；`comparable` 约束支持 `==` 与 `!=`；`~T` 表示「底层类型为 T 的任意命名类型」，这是让自定义类型也能使用泛型函数的关键。

```go
package main

import "fmt"

type Number interface {
	~int | ~int64 | ~float64
}

func Sum[T Number](values []T) T {
	var total T
	for _, v := range values {
		total += v
	}
	return total
}

func Map[T, U any](values []T, f func(T) U) []U {
	out := make([]U, 0, len(values))
	for _, v := range values {
		out = append(out, f(v))
	}
	return out
}

func main() {
	fmt.Println(Sum([]int{1, 2, 3}))
	fmt.Println(Sum([]float64{1.5, 2.5}))
	fmt.Println(Map([]int{1, 2, 3}, func(v int) string { return fmt.Sprint(v * 2) }))
}
```

泛型适合容器、算法与「对多种类型做同一件事」的工具函数。若只有一两个具体类型，写普通函数更简单；泛型会增加类型签名复杂度，不应为了炫技而用。

类型推断让调用处通常不必写类型参数，Go 会从实参推断；推断失败时仍需显式指定，例如 `Sum[float64](nil)`。约束里可以包含方法，如 `interface{ ~int; String() string }`，此时只有同时满足底层类型与方法集的类型才能使用。泛型在编译期实例化，运行时没有反射开销，但每个类型组合都会生成对应代码，类型参数过多会增大二进制体积。

Go 的泛型有几个明确限制：方法不能声明自己的类型参数；类型参数不能用于 type switch 的具体分支；也不能对类型参数使用字段访问。这些限制让实现保持简单，遇到时需要退回到接口或具体类型。

## 1.21+ 的 slices、maps 与内建函数

Go 1.21 新增 `slices`、`maps` 标准库包，以及内建 `min`、`max`、`clear`；`for range` 整数则是 Go 1.22 的语言变更。以下写法需要 Go 1.21+：

```go
// 需要 Go 1.21+，在 1.20 上无法编译
package main

import (
	"fmt"
	"slices"
)

func main() {
	nums := []int{3, 1, 2}
	slices.Sort(nums)
	idx, found := slices.BinarySearch(nums, 2)
	fmt.Println(nums, idx, found)
}
```

`for range int` 需要 Go 1.22+，实际项目应以 `go.mod` 声明的版本为准。兼容 1.20 时，排序用 `sort.Ints`，遍历用 `for i := 0; i < n; i++`。

## 字符串与转换

`strings` 与 `bytes` 的 API 高度对应：处理文本用前者，处理二进制或想避免复制用后者。JSON 解码到未知结构时可以用 `map[string]any`，但后续类型断言繁琐，结构体更可控；需要宽松解析时用 `json.Decoder` 配合 `DisallowUnknownFields` 控制严格程度。排序方面，1.21+ 的 `slices.SortFunc` 比 `sort.Slice` 的反射方案类型更安全，旧版本仍可用后者。`strconv.ParseFloat` 返回 `float64` 与 `error`，与 `Atoi` 一样必须检查错误。

```go
package main

import (
	"fmt"
	"strconv"
	"strings"
)

func main() {
	parts := strings.Split("go,rust,python", ",")
	fmt.Println(strings.Join(parts, " | "))

	n, err := strconv.Atoi("42")
	if err != nil {
		fmt.Println("转换失败:", err)
		return
	}
	fmt.Println(n+1, strconv.FormatBool(n > 0))
}
```

## 时间与 JSON

`time.Time` 带时区信息，序列化为 RFC 3339；`time.Duration` 用 `time.Second` 这类常量表达，不要硬编码纳秒。JSON 通过结构体标签控制字段名，`omitempty` 在零值时省略字段。

```go
package main

import (
	"encoding/json"
	"fmt"
	"time"
)

type Event struct {
	Name string    `json:"name"`
	At   time.Time `json:"at"`
}

func main() {
	e := Event{Name: "上线", At: time.Date(2026, 10, 27, 22, 30, 0, 0, time.UTC)}
	data, err := json.Marshal(e)
	if err != nil {
		fmt.Println("marshal:", err)
		return
	}
	fmt.Println(string(data))

	var back Event
	if err := json.Unmarshal(data, &back); err != nil {
		fmt.Println("unmarshal:", err)
		return
	}
	fmt.Println(back.Name, back.At.Format(time.RFC3339))
}
```

## net/http 最小服务

`http.HandleFunc` 注册路由，`http.ListenAndServe` 启动服务。`Handler` 接口只有一个 `ServeHTTP(ResponseWriter, *Request)` 方法，`http.HandlerFunc` 让普通函数也能作为处理器。生产代码应设置 `ReadHeaderTimeout`、`ReadTimeout`、`WriteTimeout` 与 `IdleTimeout`，并用 `http.Server` 显式配置，而不是依赖默认值——默认没有写超时，慢客户端会长期占用连接。

## 常见坑

- **约束写成 `int | float64` 却传入自定义类型**：需要 `~int | ~float64`。
- **以为泛型能做运行时类型判断**：类型参数在编译期擦除，仍需 type switch。
- **JSON 字段未导出**：小写字段不会被序列化。
- **时间用 `time.Now()` 直接比较**：跨时区展示要先 `In(loc)`。
- **HTTP 默认无超时**：慢客户端会长期占用连接。
- **忽略标准库的版本差异**：同一 API 在旧版本可能不存在，编译报错时先确认 Go 版本与 `go.mod` 声明。
