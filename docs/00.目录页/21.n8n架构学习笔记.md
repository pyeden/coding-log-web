## 这套笔记解决什么问题

n8n 上手很快，难的是把它放进生产之后还能解释清楚：为什么 Webhook 上线后 404、为什么失败重试会重复发消息、为什么数据库半年涨到几十 GB、为什么扩容之后凭据随机失效。这套笔记不逐个介绍节点，而是沿着「定义 → 执行 → 数据 → 扩展 → 部署 → 运维」这条线，把运行时模型讲透。

## 阅读顺序

1. **导读**：先建立定位，明确 n8n 与 Zapier、Dify 一类产品的边界。
2. **架构总览与工作流模型**：搞清编辑器只是客户端，workflow JSON 才是源文件。
3. **执行引擎与触发器**：理解一次运行的生命周期，以及入口的两套地址与三种响应。
4. **数据、扩展、部署**：item 与持久化、自定义节点与凭据、单机到队列模式。
5. **运维与安全**：可观测性、备份、升级与暴露面。

时间有限时，按 00 → 01 → 03 → 07 读，能覆盖「能不能用、怎么跑、怎么扩」三个核心问题。
