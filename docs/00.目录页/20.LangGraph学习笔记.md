## 这套笔记解决什么问题

LangGraph 常被误解成「又一个 Agent 框架」，实际上它更接近**有状态编排的骨架**：图、状态、检查点、中断。它不给更聪明的模型，只给可控的执行结构。

这套笔记按「定位 → 结构 → 控制 → 持久 → 审批 → 协作 → 观测 → 上线」的顺序展开，九篇各自独立又可连读。示例只使用官方长期稳定的核心 API，涉及版本细节处一律以官方文档为准。

## 阅读顺序

1. **导读：为什么读 LangGraph**：定位与边界，先判断你是不是目标场景。
2. **架构总览**：包分层与一次 `invoke` 的调用链。
3. **状态与图**：State、reducer、`compile()`。
4. **控制流**：条件边、循环、`Send`、`Command`。
5. **持久化**：checkpointer、线程隔离、时间旅行。
6. **人在回路**：`interrupt` 与恢复，两次 HTTP 请求的映射。
7. **多智能体**：Supervisor、Swarm、子图。
8. **流式与可观测**：`stream_mode`、事件与追踪。
9. **工程化**：部署、测试与上线清单。

时间有限时，按 00 → 02 → 04 阅读，能覆盖「怎么搭」与「怎么不出事」两条主线。
