# 底盘系统

底盘是唯一一个"用户天天用、却几乎看不见"的系统。加速、刹车、过弯、压过井盖、停车打方向，每一次输入都经过底盘传递与过滤。它的难点不在于单个零件的强度，而在于四个轮子与地面之间那几百毫秒里发生的事——力怎么传、姿态怎么变、轮胎还剩多少附着。

## 1. 这个领域解决什么问题：控制轮胎与地面的接触

底盘由悬架、转向、制动、车轮轮胎、副车架与传动半轴构成，共同承担四件事：承载、传力、控制车轮姿态、让驾驶员感知路面。所有工作最终收敛到轮胎接地印迹上的一小块面积，那块面积里的法向力、纵向力与侧向力，决定了车能跑多快、停多短、转多稳。

边界要说清。底盘不负责造型与空间，但它的布置决定了轮距、轴距、地板高度与后备箱形状；底盘不负责动力输出，但扭矩转向、驱动半轴的夹角与等长性会直接影响直线稳定性；底盘不写软件，但线控底盘的所有功能都建立在电子电气架构的供电与通信时延之上。

底盘的三个属性天然对立：舒适要软、操控要硬、耐久要强。软的悬架过滤冲击但侧倾大，硬的悬架响应快但颠；大行程能吸收冲击但占用空间、抬高重心；大直径防倾杆抑制侧倾但降低单轮附着力。底盘工程的全部技术含量，就是在这三角里找到与产品定位匹配的那个点，并让它在满载、空载、冷胎、热胎、新胎、磨损胎的所有组合下都不失控。

还有一个常被忽视的维度：底盘是整车感知质量最诚实的部分。加速时车头抬多少、刹车时点多少头、过坎后余振几下、方向盘中间位置的虚位有多大，这些细节无法用造型掩盖，也很难靠软件伪装（刻意滤波会同时牺牲路感）。同一套硬件，调校差一档，开起来就是廉价与高级的区别。这也是为什么底盘能力很难靠采购获得——零件可以买，标定买不到。

## 2. 在整车开发流程中的位置

上游是整车性能目标：百公里制动距离、麋鹿测试通过车速、弯道极限、冲击舒适性评分。下游是零部件供应商、调校团队与生产线。

| 阶段 | 输入 | 底盘输出 | 验证手段 |
| --- | --- | --- | --- |
| 概念 | 整车定位、平台方案 | 悬架形式、转向形式、制动方案 | 对标分析与包络估算 |
| 方案 | 硬点初版、轮胎规格 | 硬点图、K&C 目标、制动系统匹配 | 多体动力学仿真 |
| 详细设计 | 冻结硬点、载荷谱 | 零件图纸、衬套刚度曲线、弹簧减振器参数 | 台架与零部件试验 |
| 样车 | 样车、试制件 | 调校方案、问题清单 | 试验场主观与客观评价 |
| 投产 | 量产件、工艺参数 | 四轮定位规范、拧紧规范 | 下线检测与一致性抽检 |

顺序上的关键是硬点冻结。硬点一动，弹簧、减振器、稳定杆、衬套、转向机位置、半轴长度全部要重算，供应商的样件也要重做。所以硬点评审必须把操稳、平顺、包络、制造可行性放在同一张桌子上，而不是各系统分别签字。

## 3. 核心概念与术语表

| 术语 | 英文全称 | 一句话解释 |
| --- | --- | --- |
| 麦弗逊悬架 | MacPherson Strut | 用减振器兼作上导向的单横臂独立悬架 |
| 双叉臂悬架 | Double Wishbone | 上下两组叉臂控制车轮姿态的独立悬架 |
| 多连杆悬架 | Multilink Suspension | 用三根以上连杆解耦车轮运动参数的悬架 |
| 扭力梁 | Torsion Beam | 左右轮通过可扭转横梁连接的非独立悬架 |
| 空气悬架 | Air Suspension | 用气囊代替钢弹簧并可调高度与刚度的悬架 |
| 电动助力转向 | Electric Power Steering (EPS) | 电机提供转向助力的转向系统 |
| 齿条助力式电动转向 | Rack-mounted EPS (R-EPS) | 助力电机布置在齿条上的 EPS 形式 |
| 线控转向 | Steer-by-Wire (SBW) | 取消机械连接、由信号传递转向意图 |
| 电子稳定控制 | Electronic Stability Control (ESC) | 通过单轮制动纠正车辆姿态的系统 |
| 电子驻车制动 | Electric Park Brake (EPB) | 用电机代替手刹拉线的驻车系统 |
| 运动学与柔度特性 | Kinematics and Compliance (K&C) | 描述车轮在跳动与受力时姿态变化的试验 |
| 不足转向梯度 | Understeer Gradient | 衡量车辆转向响应随侧向加速度变化的量 |
| 簧下质量 | Unsprung Mass | 弹簧以下随路面跳动的质量 |
| 抗俯仰与抗蹲伏 | Anti-dive / Anti-squat | 用悬架几何抑制制动点头与加速后蹲 |
| 制动踏板感 | Brake Pedal Feel | 踏板力与减速度、行程的关系曲线 |

## 4. 主流技术方案与取舍

| 方案 | 适用场景 | 代价 |
| --- | --- | --- |
| 麦弗逊加扭力梁 | 经济型车、紧凑级 | 极限操稳与外倾控制弱，调校窗口窄 |
| 麦弗逊加多连杆 | 主流乘用车 | 零件多、成本高，衬套匹配复杂 |
| 双叉臂加多连杆 | 中大型车、性能车 | 布置占用大，重量与成本高 |
| 空气悬架加连续阻尼控制 | 高端车、需要高度调节的车型 | 系统复杂、能耗与故障率上升 |
| 液压制动加 ESC | 全系主流 | 踏板感与能量回收协调难 |
| 线控制动（One-box） | 新能源车、需要长续航回收 | 失去机械备份，功能安全要求高 |
| 线控转向 | 高阶智驾、可变转向比 | 需冗余电源与通信，法规与用户接受度待成熟 |

选择逻辑不是"越高级越好"，而是"定位与成本允许的范围内，把最影响体验的那一项做到位"。家用车把衬套与减振器阀系调好，收益远大于换双叉臂；性能车则相反，几何与刚度上限决定了天花板。

转向系统的取舍同样明显。C-EPS（管柱助力）成本低、布置容易，但助力上限受限；R-EPS 助力大、路感清晰，成本与前围空间占用上升；线控转向能解耦转向比与手感，但必须解决失效后的可控性与法规准入，通常需要双绕组电机、双电源与冗余通信。

制动系统的分水岭是能量回收。液压制动加 ESC 的方案成熟可靠，但回收与摩擦制动的切换容易产生踏板感突变；One-box 方案把助力、稳定控制与回收集成，踏板感一致性好，代价是系统失效模式更复杂，必须做完整的失效分析与降级策略。

## 5. 关键交付物与评审要点

| 交付物 | 内容 | 评审要点 |
| --- | --- | --- |
| 硬点图 | 悬架各连接点三维坐标与公差 | 是否与包络、传动、转向干涉校核过 |
| K&C 报告 | 跳动、侧倾、纵倾工况下的姿态变化 | 是否符合目标曲线，是否与仿真对齐 |
| 制动系统匹配报告 | 制动力分配、踏板行程、热容量 | 是否满足法规与热衰退要求 |
| 调校记录 | 弹簧、减振器、稳定杆、衬套、胎压组合 | 每组参数的变更理由是否可追溯 |
| 零部件 DVP | 疲劳、腐蚀、密封、NVH 试验 | 载荷谱是否来自真实路况 |
| 下线检测规范 | 四轮定位、制动力、转向角 | 限值是否与设计目标一致 |

评审最容易漏的是"边界状态"。空载与满载的姿态差异、冷胎与热胎的附着差异、制动热衰退后的距离增长，这些才是用户真实会遇到的状态。只报最佳工况的数据，等于没有验证。

另一个重点是主观与客观的对应关系。同一组 K&C 数据，不同调校师能做出完全不同的手感，因为减振器阀系的细节、衬套的非线性、转向机的摩擦都不在稳态数据里。所以调校必须由人完成，数据只用于缩小搜索范围，不能代替判断。

## 6. 标准、法规与工具链

制动：GB 21670《乘用车制动系统技术要求及试验方法》、ECE R13-H（轻型车制动）。转向：GB 17675《汽车转向系 基本要求》、ECE R79（转向装置）。操稳试验：ISO 3888-2（双移线，即麋鹿测试的标准化路径）、GB/T 6323（汽车操纵稳定性试验方法）。功能安全：ISO 26262:2018，制动与转向通常需达到较高完整性等级。轮胎：GB 9743 等强制性标准。线控转向与线控制动的国标与准入要求近年持续更新，具体条款以最新官方发布为准。

工具链：多体动力学用 Adams/Car、Simpack、CarSim；K&C 试验台用于测量悬架运动学与柔度特性；台架试验覆盖制动热衰退、转向耐久、减振器示功；HIL（Hardware-in-the-Loop，硬件在环）用于验证 ESC 与线控系统的失效降级；数据采集与主观评价用整车测试系统配合标准评价表。

## 7. 与其他领域的接口与常见冲突

**与车身的接口**：悬架安装点刚度、轮罩包络、地板高度三者互相牵制（见[车身与内外饰](/note/body-interior/)）。安装点刚度不足会让衬套隔振失效，路面冲击直接传入座舱；轮罩太小则限制轮胎规格与转向角。冲突的解决通常靠局部加强筋与铸铝塔座，代价是重量与成本。

**与 EEA 的接口**：线控底盘把安全责任转移到电气系统上。ESC、EPS、EPB、线控制动都要在供电中断、通信超时、传感器失效时给出明确的降级策略（见 [EEA 学习笔记](/note/eea/)中的[功能安全与信息安全](/pages/ae5d1c8b3f720694/)与[电源与配电架构](/pages/1d7e4b9a6c2f8350/)）。常见冲突是整车静态电流预算与底盘常电需求打架，或总线负载升高导致控制指令时延超出标定假设。

**与整车集成的接口**：操稳与平顺的取舍就是底盘与集成的日常（见[整车集成与性能属性](/note/vehicle-integration/)）。集成要的是全工况均衡，底盘调校追求的是特定场景的极致。裁决依据只能是产品定位与目标用户的使用场景，而不是谁的声音大。

**与动力的接口**：扭矩转向、驱动半轴夹角、电机瞬时扭矩响应都会影响直线稳定性与轮胎寿命。大扭矩车型必须做等长半轴或中间轴设计，代价是布置空间与重量。

## 8. 常见坑与检查清单

- [ ] 硬点冻结前是否做过包络、传动、转向的全工况干涉校核
- [ ] K&C 目标是否与仿真模型对齐，模型是否用实车数据标定
- [ ] 弹簧、减振器、稳定杆的组合是否在满载与空载下都验证过
- [ ] 制动系统是否做过热衰退与涉水恢复试验
- [ ] 线控系统的失效降级策略是否覆盖断电、通信超时与传感器故障
- [ ] 衬套刚度曲线是否考虑温度与老化后的变化
- [ ] 四轮定位参数是否给出量产公差与调整方法
- [ ] 轮胎规格变更后是否重新验证制动距离与滚阻

## 9. 学习路径与资料

入门先补物理直觉：车辆动力学里的轮胎侧偏特性、载荷转移、不足转向梯度这三个概念，能解释路上八成的操控现象。推荐配合简单的二自由度模型手算一遍，比看公式推导更有用。

进阶分三条线。第一条是多体动力学仿真：在 Adams/Car 或 CarSim 里搭一套悬架，做硬点灵敏度分析，理解每个坐标变化对前束、外倾、抗俯仰的影响。第二条是试验：跟一次 K&C 试验和一次试验场主观评价，看数据与感受如何对应。第三条是标定：从减振器示功图入手，理解阀系如何决定车身控制与冲击隔离的平衡。

资料优先级：国标与 ECE 法规的试验方法最可靠，其次是车辆动力学教材与 SAE 论文，再次是零部件供应商的公开技术资料。标准号与版本以官方最新发布为准，本文中的参数仅作量级参考。
