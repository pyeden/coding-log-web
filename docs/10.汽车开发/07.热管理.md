# 热管理

电动车的热管理有一个残酷的底层事实：车内几乎所有的能量最终都变成热，而电芯、功率器件、座舱这三类对象对温度的要求彼此冲突。电芯要待在二十多度的窄窗口里，电驱允许更热但怕局部热点，人要大范围可调且反应迅速。热管理不是"加个散热器"，而是在有限的冷量与热量之间做调度，并且要在零下二十度和四十度暴晒这两种极端下都不崩。

## 1. 这个领域解决什么问题

先分清三类热负荷。**电芯**是唯一对温度既敏感又苛刻的对象：温度低，内阻上升、可用功率下降、充电析锂风险上升；温度高，副反应加速、寿命快速衰减；温差大，包内不同电芯的老化速率不一致，木桶效应提前出现。**电驱与功率电子**的容忍范围宽得多，但局部热点会让器件提前失效，所以关注的是结温与流量分配的均匀性。**座舱**则是一个舒适性与能耗的博弈场，冬季采暖在电动车上是纯消耗，夏季降温同样吃电。

这三类对象的温度目标不同，却共享同一套冷源和热源。热管理的核心工作就是设计这套共享架构，并定义当冷量或热量不够时谁优先。边界上，热管理不决定整车的气动外形与前舱进气开口，那是车身与空气动力学的事；也不决定电机的功率MAP，那是三电的事。它提供的是"能力边界"：在某个环境温度下，系统能持续带走多少热，超出这个边界，动力系统就必须降额。

一个必须先建立的认知是：热管理不是稳态问题，而是瞬态问题。整车热平衡试验给出的是稳态能力，用户感受到的却是"连续三次全油门之后动力变弱"这种瞬态现象。热容、流量、阀切换的响应时间，往往比峰值散热功率更能决定体验。

## 2. 在整车开发流程中的位置

上游是三电与整车集成：电池包的发热功率曲线、电驱的损耗 MAP、整车的目标能耗。下游是标定、试验与售后。热管理是典型的"接口密集型"领域，它自己不产生动力，却决定了动力能不能持续输出。

| 阶段 | 热管理侧输入 | 关键输出 | 门禁关注点 |
| --- | --- | --- | --- |
| 产品定义 | 目标市场气候带、续航目标、快充诉求 | 热管理架构选型（风冷/液冷/直冷、是否热泵） | 极端气候下的能耗与充电可行性 |
| 概念设计 | 电池包包络、前舱空间、整车热负荷估算 | 回路拓扑、冷板方案、压缩机与水泵选型 | 前舱布置、管路走向可行性 |
| 方案设计 | 发热功率曲线、环境工况定义 | 换热器面积、管路口径、阀件配置 | 最恶劣工况的热平衡余量 |
| 详细设计 | 冻结数模、CFD 边界条件 | 冷板流道、风道、密封与排气路径 | 温差指标、热失控排气方向 |
| 样车验证 | 环境舱、试验场 | 热平衡、快充升温、低温冷启动、除霜除雾 | 降额策略是否与实测一致 |
| 工装试生产 | 产线加注与检漏工艺 | 加注量规范、检漏判据、EOL 规范 | 一次通过率、售后可维修性 |
| 认证量产 | 法规试验计划 | 热扩散报告、空调与除雾合规 | 认证项目全覆盖 |

最容易被低估的时点是"回路拓扑冻结"。一旦管路走向、阀件位置、冷板接口定下来，后面所有优化都只能在软件标定里做，物理层面的余量已经没了。所以拓扑评审必须带着最恶劣工况的数据去开，而不是带着一张漂亮的示意图。

## 3. 核心概念与术语表

| 术语 | 英文全称 | 一句话解释 |
| --- | --- | --- |
| 液冷板 | Cold Plate | 贴在电芯底部或侧面的流道板，负责把热量导入冷却液 |
| 冷媒直冷 | Direct Refrigerant Cooling | 制冷剂直接在板内蒸发吸热，省去中间水回路 |
| 冷却液 | Coolant | 通常是乙二醇水溶液，兼顾防冻、防腐与导热 |
| 电子膨胀阀 | Electronic Expansion Valve (EXV) | 精确调节制冷剂流量，是热泵与直冷系统的关键执行器 |
| 换热器 | Chiller | 制冷剂与水路之间的换热部件，实现电池冷却 |
| 热泵 | Heat Pump | 逆循环取热，用少量电搬运环境或余热的热量 |
| 正温度系数加热器 | Positive Temperature Coefficient Heater (PTC) | 电加热元件，简单可靠但 1 度电只能换 1 度热 |
| 余热回收 | Waste Heat Recovery | 把电驱、电控的废热导入座舱或电池，减少 PTC 消耗 |
| 多通阀 | Multi-way Valve | 切换回路串并联关系，是集成式热管理模块的核心 |
| 热失控 | Thermal Runaway | 电芯内部放热失控，需靠隔热与定向排气控制后果 |
| 排气阀 | Vent Valve / Pressure Relief Valve | 包体泄压通道，决定热失控气体的排放方向 |
| 气凝胶 | Aerogel | 低导热隔热材料，用于阻断电芯间的热扩散 |
| 导热结构胶 | Thermally Conductive Adhesive | 兼顾粘接与导热，把电芯热量传到冷板 |
| 计算流体力学 | Computational Fluid Dynamics (CFD) | 仿真流场与温度场，替代部分试验但依赖边界条件 |
| 浸车 | Soak | 车辆在恒温环境中静置至热平衡，是试验的起始条件 |
| 热平衡 | Thermal Balance | 发热与散热达到稳态，用于评价持续能力 |

## 4. 主流技术方案与取舍

| 方案 | 优势 | 代价与限制 |
| --- | --- | --- |
| 自然风冷 | 结构最简单、成本最低、无漏液风险 | 散热能力弱，包内温差大，快充与高温工况基本不可行 |
| 强制风冷 | 成本低、布置灵活 | 风道占用空间、噪声大、均匀性差，难以支撑高倍率 |
| 液冷（冷板） | 换热能力强、温差可控、可与电驱共回路 | 存在漏液与腐蚀风险，管路重量与成本上升，需除气与检漏 |
| 冷媒直冷 | 换热效率高、省去水回路、降温速度快 | 制冷剂分布均匀性难控，控制复杂，维修体系要求高 |
| PTC 采暖 | 结构简单、响应快、低温可靠 | 能耗高，冬季续航衰减明显 |
| 热泵采暖 | 能效比高，显著改善冬季续航 | 低温制热能力衰减，需除霜策略，系统复杂度与成本上升 |
| 热泵 + 余热回收 | 进一步降低采暖能耗，回收电驱废热 | 回路耦合复杂，阀件多，标定工作量大，故障模式增多 |
| 单回路串联 | 结构简单、零件少、成本低 | 各对象温度目标被迫折中，无法独立控制 |
| 分区多回路 | 电池、电驱、座舱可独立调温，优先级可编排 | 阀件与管路多，控制策略复杂，重量与成本上升 |
| 集成式热管理模块 | 减少管路与接头、提升装配效率、便于平台复用 | 前期开发投入大，维修时整体更换成本高 |

选择的核心不是"哪个技术更先进"，而是"目标市场的气候分布"。在四季温和的地区，热泵的溢价可能十年收不回来；在冬季漫长的北方，没有热泵或余热回收的车型会被用户直接判死。同理，主打超快充的车型必须上液冷甚至直冷，而 A00 级代步车用风冷也能活得很好。

还有一个取舍常被忽略：集成度与可维修性。集成式模块把十几个阀和泵塞进一个盒子，装配线上省事，但售后一旦内部泄漏，只能整体更换，保修成本会反噬。设计时要明确"可拆解层级"，哪些件允许单独换，哪些件必须整体换，这条要写进售后策略。

## 5. 关键交付物与评审要点

**仿真类**：整车级热平衡仿真、电池包 CFD（含温差云图）、座舱降温与除霜仿真、热失控气体流动仿真。**试验类**：高温怠速与高速爬坡热平衡、高温快充温升曲线、低温冷启动与低温充电、浸车后的降温速率、除霜除雾法规试验、电池包热扩散试验。**标定类**：压缩机转速与 EXV 开度 MAP、水泵流量策略、多通阀切换逻辑、风扇控制、降额曲线。**文档类**：热管理架构图与模式表、故障降级矩阵、加注量与检漏规范。

评审要点有三个。第一，模式表是否穷举。热管理的复杂度不在单个模式，而在模式切换：从"电池冷却"切到"电池加热"再切到"座舱除霜"，中间经过哪些阀位、是否有短暂的无冷却窗口。第二，温差指标是否有实测支撑。包内温差要求通常在几度以内，这个数字必须来自最恶劣工况的实测，而不是仿真。第三，降额策略是否与用户感知一致。动力突然变弱而没有提示，是投诉高发点。

一个实操建议：把"最差组合"列成矩阵——最高环境温度配最大快充功率、最低温度配最大采暖需求、高 SOC 配长下坡连续回收。每个组合都要求有实测或可信仿真，缺一项就是一个未关闭的风险。

## 6. 标准、法规与工具链

安全与法规：GB 38031《电动汽车用动力蓄电池安全要求》中的热扩散试验是核心，判据与实施日期以最新官方发布为准；GB 18384《电动汽车安全要求》涉及温度与防护；GB 7258《机动车运行安全技术条件》涉及除霜除雾与视野。环境适应性：ISO 16750 系列（道路车辆电气电子设备的环境条件与试验）、对应的 GB/T 28046 系列。空调与制冷剂：关注制冷剂法规的演进（如 R134a 向低全球变暖潜能值工质的切换），具体禁用时间表以官方发布为准。

工具链：一维系统仿真用 AMESim、GT-SUITE、Simulink 搭建回路与控制器联合模型；三维 CFD 用 Fluent、STAR-CCM+、TAITherm 做包内与座舱温度场；标定用 INCA、CANape；试验依赖环境舱、整车风洞与试验场。数据的组织方式比工具本身更重要——每个工况要有唯一编号，并与需求、标定版本、软件版本绑定，否则三个月后没人说得清那条曲线是哪版软件跑的。

## 7. 与其他领域的接口与常见冲突

**与三电的接口**：电池的发热功率曲线、电驱的损耗 MAP 是热管理的输入，热管理返回的是"允许的持续功率"。冲突最典型：三电希望标一个漂亮的持续功率，热管理算出来在四十度环境下达不到。解决办法是在方案阶段就共同定义"降额拐点"，并把它写进整车性能目标，而不是各自留一手（见[动力总成与三电](/note/powertrain/)）。

**与 EEA 的接口**：热管理模块的执行器多、报文多，阀位与泵速的响应直接影响温控品质。冲突在于通信周期与故障诊断：一个阀的响应延迟几百毫秒，在模式切换时足以造成温度波动。架构上要把热管理域的控制周期与诊断需求提前提出（见 [EEA 学习笔记](/note/eea/)），不要等软件集成时才发现总线负载不够。

**与整车集成的接口**：冬季采暖与夏季降温直接吃掉续航，是能耗目标的最大变量之一（见[整车集成与性能属性](/note/vehicle-integration/)）。冲突在于公告续航与用户实际体验的差距：试验循环里的空调负荷是标准化的，真实使用中用户会提前远程开启空调。处理办法是在能耗目标里显式拆出"空调附加能耗"，并做敏感性分析。

**与车身的接口**：前舱进气开口、格栅主动关闭、底盘护板与管路走向共同决定换热能力与风阻（见[车身与内外饰](/note/body-interior/)）。冲突是风阻与散热的对立：开口越大散热越好、风阻越高。主动格栅能缓解，但增加了故障点与成本，且要在碰撞后仍保证开口不被卡死。

**与底盘/安全的接口**：管路布置要避开碰撞吸能区与地面异物冲击区，电池包排气方向不能朝向乘员舱或易燃部位（见[底盘系统](/note/chassis/)）。这条经常在样车阶段才暴露：管路为了避让悬架摆臂走了低位，结果通过性试验时被刮伤。

## 8. 常见坑与检查清单

- [ ] 冷板流道的均温性是否在最恶劣工况下实测，而非仅用台架单包数据外推
- [ ] 热仿真边界条件（太阳辐射、地面反射、舱内人员负荷）是否与试验对齐
- [ ] 快充末端的产热峰值是否单独标定，而不是沿用平均发热功率
- [ ] 热失控排气路径是否做过整车级验证，方向不朝向乘员舱与高压部件
- [ ] 低温加热功率是否与电池可接受充电功率匹配，避免"加热等太久"
- [ ] 模式切换过程中是否存在无冷却/无采暖的空窗期，时长是否可接受
- [ ] 除霜除雾的优先级是否高于座舱舒适性，且符合法规要求
- [ ] 售后加注量、检漏判据与 EOL 判据是否统一，避免维修后反复报警

## 9. 学习路径与资料

先建立传热学的基本功：导热、对流、辐射三者的量级关系，以及热阻网络怎么用来做快速估算。很多人一上来就学 CFD 软件，结果算出的温度场很漂亮却解释不了为什么实测偏高——问题往往出在边界条件，而不是求解器。

第二步学制冷循环：压焓图、过热度、热泵在低温下能力衰减的机理、除霜为什么必须周期性中断制热。理解了循环，才看得懂为什么同样标称功率的热泵在零下十度和零下二十度表现完全不同。

第三步学系统集成：多回路拓扑、阀件组合、模式切换逻辑。这部分最好的教材是拆解报告与主机厂的架构图，配合一维仿真自己搭一遍回路，比读十篇文章有用。

资料优先级：国家标准与法规原文（GB 38031、GB 7258）高于 ISO 16750 与 GB/T 28046 等环境试验标准，高于主机厂公开白皮书，高于综述文章。学术侧可关注车辆热管理方向的综述论文，但要注意其工况假设与量产约束的差距。

实践上，跟一次环境舱试验胜过读一个月书：你会看到浸车时间不够导致的假数据、看到传感器布置位置如何影响结论、看到模式切换时那几分钟的温度波动。热管理是一个必须"看见"的领域。
