# 整车安全与法规

安全是一个很少被用户直接感知、却在出事那天决定一切的属性。它的特殊性在于：你无法用"用户体验"来验证它，只能靠标准化的试验、可追溯的分析和冗余的设计来证明它。更麻烦的是，安全的三条线索——碰撞后保护人、碰撞前避免碰撞、电子系统失效时不造成危害——分属三个不同的学科体系，用三套不同的语言说话，却要在同一台车上共存。

## 1. 这个领域解决什么问题

第一条是**被动安全**，也叫碰撞安全。它假设事故已经发生，目标是让乘员舱尽可能完整、让乘员在约束系统作用下减速得尽可能平缓、让车外行人受到的伤害尽可能轻。它的证据是碰撞试验与 CAE 仿真，评价指标是假人伤害值。

第二条是**主动安全**，目标是让事故不发生或少发生。ABS、ESC、AEB、LKA 都属于这一类。它的证据是场景测试与实车标定，评价指标是误报率、漏报率与介入时机。

第三条是**电子电气系统的安全**，包括功能安全与预期功能安全。它不问"撞了会怎样"，而问"控制系统失效或能力不足时，会不会自己制造事故"。它的证据是分析过程——危害分析、安全目标、安全机制、验证报告，也就是所谓的安全案例。

这三条线索的边界必须说清。被动安全不负责防止事故，主动安全不负责碰撞后的生存空间，功能安全不负责机械结构的强度。它们之间还有大量灰色地带：AEB 该在什么时机介入、介入后如果仍然撞上，责任如何划分——这类问题最终落在整车层面的安全概念里，而不是某个系统单独能回答。

一个常见的误解是把"通过五星"当成安全设计的终点。星级是法规与评价体系下的相对结果，它约束的是试验工况；真实事故的工况分布远比试验宽。工程上更可靠的做法是把安全目标拆成"法规必须过、评价尽量高、真实工况有冗余"三层，三层用不同的证据链，而不是用一套试验应付所有。

## 2. 在整车开发流程中的位置

安全是典型的"前置约束型"领域：它不产出造型，但决定造型能不能成立；它不设计底盘，但决定底盘硬点能放在哪里。越晚介入，代价越大。

| 阶段 | 安全侧输入 | 关键输出 | 门禁关注点 |
| --- | --- | --- | --- |
| 产品定义 | 目标市场、目标星级、法规清单 | 安全目标书、适用法规矩阵 | 目标市场法规是否覆盖全 |
| 概念设计 | 总布置、平台结构 | 传力路径方案、约束系统配置 | 碰撞路径是否连续、有无断点 |
| 方案设计 | 车身结构方案、气囊布置 | 碰撞 CAE 首轮结果、HARA 初稿 | 关键工况是否有达标路径 |
| 详细设计 | 冻结数模、材料牌号 | 碰撞仿真收敛、约束系统参数、安全机制设计 | 仿真与历史试验的相关性 |
| 样车验证 | 样车、滑台、试验场 | 滑台与整车碰撞报告、AEB 场景测试 | 假人伤害值余量、误触发率 |
| 工装试生产 | 模具件、工艺偏差 | 一致性验证、生产一致性检查 | 材料与料厚是否漂移 |
| 认证量产 | 申报材料 | 公告与 CCC、出口型式认证 | 认证项目与量产状态一致 |

两个时点最关键。第一是**传力路径冻结**，通常在概念设计末期。一旦纵梁走向、门槛截面、B 柱加强板定下来，后面只能靠加厚加料补救，重量与成本双输。第二是**约束系统标定窗口**，它必须在整车碰撞试验之前完成滑台验证，否则整车试验会变成"用真车试参数"，每轮都是几十万。

## 3. 核心概念与术语表

| 术语 | 英文全称 | 一句话解释 |
| --- | --- | --- |
| 承载式车身 | Unibody | 车身与底盘合一，靠结构件共同承载，乘用车主流 |
| 吸能盒 | Crash Box | 纵梁前端的可压溃段，用可控变形吸收低速碰撞能量 |
| 传力路径 | Load Path | 碰撞力从保险杠传到门槛、地板、B 柱的连续通道 |
| 乘员舱完整性 | Occupant Cell Integrity | 碰撞后乘员生存空间不被侵入的程度 |
| 约束系统 | Restraint System | 安全带、预紧器、限力器、气囊的统称 |
| 预紧器 | Pretensioner | 碰撞初期收紧安全带，消除松弛量 |
| 限力器 | Load Limiter | 限制安全带拉力，避免胸部伤害过高 |
| 鞭打伤害 | Whiplash | 追尾时颈部过度后仰造成的损伤 |
| 行人保护 | Pedestrian Protection | 通过前部造型与吸能结构降低对行人的伤害 |
| 新车评价规程 | New Car Assessment Programme (NCAP) | 独立机构的星级评价，严于法规 |
| 中国新车评价规程 | China-New Car Assessment Program (C-NCAP) | 中汽中心主导的新车安全星级评价，要求严于法规 |
| 中国保险汽车安全指数 | China Insurance Automotive Safety Index (C-IASI) | 偏重维修经济性与小偏置/侧面碰撞等工况 |
| 危害分析与风险评估 | Hazard Analysis and Risk Assessment (HARA) | 识别危害、评定 ASIL 等级的方法 |
| 汽车安全完整性等级 | Automotive Safety Integrity Level (ASIL) | 从 A 到 D 的风险等级，D 最严 |
| 安全目标 | Safety Goal | 针对每个危害定义的高层安全要求 |
| 故障容错时间间隔 | Fault Tolerant Time Interval (FTTI) | 从故障发生到必须进入安全状态的时间窗 |
| 预期功能安全 | Safety of the Intended Functionality (SOTIF) | 处理"系统没坏但能力不足"导致的风险 |
| 自动紧急制动 | Autonomous Emergency Braking (AEB) | 识别碰撞风险并主动制动 |
| 电子稳定控制 | Electronic Stability Control (ESC) | 通过单轮制动纠正车辆失稳 |

## 4. 主流技术方案与取舍

| 方案 | 优势 | 代价与限制 |
| --- | --- | --- |
| 高强度钢笼式车身 | 成本可控、工艺成熟、维修体系完善 | 重量大，轻量化空间有限 |
| 铝合金车身/混合材料 | 减重明显，吸能特性好 | 材料与连接工艺成本高，维修难度大，需要专门产线 |
| 热成型钢关键件 | 用少量高强材料强化 B 柱、门槛等关键区 | 成形与焊接工艺复杂，回弹控制难 |
| 传统约束系统（安全带+双气囊） | 成本低，满足法规 | 小偏置、侧碰等严苛工况下保护不足 |
| 全域约束（气帘、膝部气囊、后排气囊） | 覆盖更多工况与坐姿 | 成本与布置复杂度上升，误爆风险需控制 |
| 纯被动安全 | 技术成熟、验证体系完整 | 只能减轻后果，不能减少事故 |
| 被动 + 主动融合 | 主动系统提前介入，被动系统按需触发 | 系统耦合复杂，责任边界与冗余设计难 |
| 法规合规导向 | 目标明确、投入可控 | 只满足下限，真实工况冗余不足 |
| 评价规程导向（五星） | 市场传播价值高 | 容易过拟合试验工况，忽视非标准场景 |
| 功能安全（ISO 26262）流程 | 系统化降低 E/E 失效风险 | 文档与验证成本高，对供应商管理要求强 |
| SOTIF 分析 | 覆盖感知与算法能力不足的场景 | 场景空间近乎无限，验证只能靠统计与论证 |

选择的核心是产品定位与市场。出口欧洲的车型必须按 ECE 法规与 Euro NCAP 设计，国内主打性价比的车型则要在 C-NCAP 与成本之间找平衡。但有一条底线不能妥协：法规项是准入条件，不是优化目标。任何为了造型或成本而挤压法规余量的方案，最终都会在认证阶段以更高的代价还回来。

## 5. 关键交付物与评审要点

**仿真类**：正面 100% 与偏置碰撞、侧面碰撞、后碰、顶部抗压、行人保护的 CAE 报告，附模型相关性分析与网格无关性说明。**试验类**：滑台试验（约束系统标定）、整车碰撞试验、气囊点爆试验、安全带固定点强度、座椅鞭打试验、AEB 与 ESC 的场景测试。**分析类**：HARA 报告、安全目标与安全概念、安全案例（Safety Case）、DFMEA 与 FTA。**认证类**：公告申报材料、CCC 认证、出口型式认证文件。

评审最该问的三件事。第一，**仿真与试验的相关性**。CAE 报告如果只给结果不给标定过程，等于没给证据。要求提供至少一组历史车型的仿真-试验对比，误差在可接受范围内才谈得上预测能力。第二，**余量**。假人伤害值刚好卡在限值上，量产一致性波动就会导致复测不合格。工程上通常要求留出可量化的余量，并把材料料厚、焊点数量的工艺公差算进去。第三，**安全机制的响应时间**。安全目标定义了 FTTI，每个安全机制都必须证明自己能在窗口内完成检测与响应，而不是只写"具备诊断功能"。

还有一个容易漏的点：**生产一致性**。碰撞安全高度依赖材料牌号、料厚、焊点质量。试生产阶段必须验证模具件与样件的一致性，否则认证用的车和量产车不是同一台车。

## 6. 标准、法规与工具链

被动安全法规（国内强检）：GB 11551《汽车正面碰撞的乘员保护》、GB 20071《汽车侧面碰撞的乘员保护》、GB 26134《乘用车顶部抗压强度》、GB 15083《汽车座椅、座椅固定装置及头枕强度要求和试验方法》、GB 7258《机动车运行安全技术条件》。出口对应 UN R94（正面碰撞）、UN R95（侧面碰撞）、UN R127（行人保护）等。电池相关：GB 38031 的碰撞后安全要求。

评价规程：C-NCAP 与 C-IASI 的版本迭代较快，试验工况、评分权重与加分项会变，做目标设定时必须锁定具体版本，本文不列具体分值。欧洲对应 Euro NCAP。

功能安全与预期功能安全：ISO 26262:2018（对应国内 GB/T 34590 系列）、ISO 21448:2022（SOTIF）、ISO/SAE 21434:2021（网络安全工程）、UN R155/R156（网络安全与软件更新）。国内整车信息安全强制性标准已发布，具体编号与实施日期以官方公告为准。

工具链：碰撞仿真用 LS-DYNA、PAM-CRASH、RADIOSS；假人与约束系统建模用 MADYMO；优化用 modeFRONTIER 或 Optimus 做多目标寻优；功能安全用 Medini Analyze、IsoGraph 做 HARA 与架构分析；需求与追溯用 Polarion、DOORS。工具能提高效率，但安全案例的说服力来自证据链的完整性，而不是工具的品牌。

## 7. 与其他领域的接口与常见冲突

**与车身的接口**：这是最紧密的一对。传力路径、材料分布、焊点与结构胶布置既是车身设计内容，也是碰撞性能的决定因素（见[车身与内外饰](/note/body-interior/)）。典型冲突是造型与行人保护：低趴的前脸好看，但发动机罩前缘高度不足会推高行人腿部伤害。解决只能在前脸造型阶段就把行人保护的目标线画出来，而不是造型冻结后再改。

**与底盘的接口**：悬架硬点、副车架结构、转向机布置都在碰撞吸能区内（见[底盘系统](/note/chassis/)）。冲突是小偏置碰撞：车轮在碰撞中会被推向后围，如果副车架与转向拉杆的连接方式不当，车轮会侵入乘员舱。处理办法是在概念阶段做"车轮后移路径"分析，必要时用脱落式副车架或断裂螺栓设计。

**与三电的接口**：电池包既是重量集中点，也是碰撞后的二次风险源（见[动力总成与三电](/note/powertrain/)）。冲突在于布置：包体要避开碰撞吸能区，又要保证离地间隙与后排坐姿。碰撞后高压自动断开的时间与可靠性，必须与约束系统的点火时序一起验证，不能各自为政。

**与 EEA 的接口**：功能安全的绝大多数安全目标落在 E/E 系统上，架构的冗余设计、通信的时效性、诊断的覆盖率都在这里决定（见 [EEA 学习笔记](/note/eea/) 中的[功能安全与信息安全](/pages/ae5d1c8b3f720694/)）。常见冲突是"降级策略没有物理出口"：软件检测到故障要求进入安全状态，但执行器本身是单点，无法独立关闭。

**与整车集成的接口**：重量、质心、轴荷分布同时影响碰撞与操控（见[整车集成与性能属性](/note/vehicle-integration/)）。冲突是轻量化与安全的正面对撞：减重最省事的地方往往是加强件。解决办法是把"安全件"明确列出，轻量化指标只对非安全件考核。

## 8. 常见坑与检查清单

- [ ] 目标市场的法规清单是否逐条核对到具体版本与实施日期
- [ ] 传力路径是否连续，有无因造型或布置造成的断点
- [ ] CAE 模型是否用历史试验数据标定过，误差范围是否量化
- [ ] 假人伤害值是否有可量化余量，且考虑了材料与工艺公差
- [ ] 约束系统是否完成滑台标定后再进整车碰撞，避免用真车试参数
- [ ] HARA 的每一个安全目标是否都能追到具体安全机制与验证证据
- [ ] 碰撞后高压断开与燃油/电池二次风险的处置是否有整车级验证
- [ ] 生产一致性检查是否覆盖材料牌号、料厚与焊点数量

## 9. 学习路径与资料

入门建议从法规原文开始，而不是从科普文章。先读 GB 11551 与 GB 20071，把试验工况、假人类型、限值搞清楚，你会立刻明白"五星"到底在测什么。然后读 C-NCAP 的管理规则，看评分体系如何引导设计取向。

第二步学结构与力学：薄壁梁的压溃模式、材料应变率效应、焊点与结构胶的失效形式。这部分决定你能不能看懂 CAE 云图，而不是只看颜色深浅。

第三步学功能安全：从 ISO 26262 的概念阶段读起，理解 HARA 如何从"危害"推到"安全目标"再到"安全需求"，以及 ASIL 分解为什么不能随便用。SOTIF 放在后面读，它更像是对功能安全的补充而非替代。

资料优先级：法规与标准原文最高，其次是 NCAP 评价规程与官方技术报告，再次是主机厂公开的安全白皮书与事故深度调查数据（如 CIDAS 类研究），最后才是科普内容。事故深度调查尤其值得看，它告诉你真实事故的工况分布与试验工况差多远。

实践上，如果能跟一次整车碰撞试验，价值超过读十篇论文：你会看到试验前的准备、传感器的布置、碰撞后的测量，以及工程师如何从一堆变形中判断力是怎么走的。安全工程的直觉，基本都是从这种现场长出来的。
