# 车身与内外饰

用户判断一台车"值不值这个价"，往往只用三秒钟：拉开车门听那一声、摸一下门板缝、坐进去看仪表台的反光。这三秒钟背后，是白车身的刚度、钣金的贴合精度、内外饰件的老化性能与装配工艺的一致性。车身与内外饰是整车开发里零件最多、模具最多、改动最贵的部分，也是最能体现工程与审美拉扯的部分。

## 1. 这个领域解决什么问题：把曲面变成可制造的结构

车身工程的边界，一边是造型（A 面、比例、特征线），一边是制造（冲压、焊装、涂装、总装）。它要做的，是把一条漂亮的曲面变成能冲出来、能焊起来、能装上去、能通过碰撞法规、能在十年后不锈不响的实体。

白车身（Body in White，BIW）负责结构：承载、传力、保护乘员、提供安装点。开闭件（Closures，四门两盖加尾门）负责使用：开合手感、密封、锁止。内外饰负责感知：视觉、触觉、气味、声音。三者共用一套尺寸体系与装配关系，任何一处偏差都会以"缝隙不均""异响""进水"的形式被用户放大。

这个领域最反直觉的一点是：好看与好造经常冲突。造型要的锐利棱线，冲压可能开裂；造型要的深拉延，模具可能需要多工序且废品率高；造型要的悬浮式车顶，密封与排水要重新设计。车身工程师的价值，不是对造型说"不行"，而是在造型冻结前给出"改这里、代价这么大"的量化选项。

还有一层容易被忽略：车身是整车开发中工装投资最重的部分。一套侧围模具、一条焊装线、一套检具，投下去就是几个月周期与八位数预算。这意味着车身的任何设计变更都要走最严格的评审，也意味着前期决策的质量被成倍放大。做过几个项目的人都会形成一个共同判断：宁可多花两周做可行性分析，也不要省掉这两周去抢进度。

内外饰的逻辑不同。它零件多、模具小、单件成本低，但供应商多、感知要求高、颜色与纹理的批次一致性极难控制。同一个黑色，注塑件、搪塑件、织物、皮革在自然光与地下车库灯光下的表现可以完全不同。所以内外饰的核心能力不是结构强度，而是标准制定与供应链管控。

## 2. 在整车开发流程中的位置

上游是造型与总布置：外表面、内表面、人机硬点、动力总成与底盘安装点。下游是涂装、总装、售后钣金件供应。

| 阶段 | 输入 | 车身输出 | 下游影响 |
| --- | --- | --- | --- |
| 概念 | 造型草图、平台边界 | 断面方案、材料策略 | 重量与成本估算 |
| 方案 | A 面初版、总布置硬点 | 主断面、传力路径、开闭件方案 | 碰撞与刚度仿真 |
| 详细设计 | 冻结 A 面、DTS 定义 | 钣金件数模与图纸、焊接装配树 | 模具开发、焊装线规划 |
| 工装验证 | 模具、夹具、检具 | 首件测量报告、匹配报告 | 尺寸链修正 |
| 试生产 | 涂装与总装工艺 | 间隙面差达标、密封验证 | 量产一致性 |

关键顺序不能颠倒：A 面冻结在前，模具开发在后，中间隔着可行性回检与主断面确认。跳过回检直接开模，是车身项目最常见的重大损失来源。

## 3. 核心概念与术语表

| 术语 | 英文全称 | 一句话解释 |
| --- | --- | --- |
| 白车身 | Body in White (BIW) | 未涂装未装配的焊接车身骨架 |
| 开闭件 | Closures | 车门、发动机罩、行李箱盖等可开启部件 |
| 尺寸技术规范 | Dimensional Technical Specification (DTS) | 规定各处间隙与面差的公差目标 |
| 间隙与面差 | Gap and Flush | 相邻钣金件之间的缝宽与高低差 |
| 成形极限图 | Forming Limit Diagram (FLD) | 判断冲压是否开裂起皱的判据曲线 |
| 回弹 | Springback | 冲压件脱模后因弹性恢复产生的变形 |
| 自冲铆接 | Self-Piercing Riveting (SPR) | 用铆钉穿透并锁合板材的连接工艺 |
| 热熔自攻螺接 | Flow Drill Screw (FDS) | 高速摩擦穿孔后攻丝的连接工艺 |
| 阴极电泳 | Cathodic Electrodeposition | 涂装前给车身做防锈底层的工艺 |
| 声学包 | Acoustic Package | 隔音吸音材料的组合方案 |
| 仪表台 | Instrument Panel (IP) | 驾驶舱前部的功能与装饰总成 |
| 感知质量 | Perceived Quality | 用户通过看摸听形成的主观品质印象 |
| 挥发性有机物 | Volatile Organic Compounds (VOC) | 内饰材料释放的有机挥发物 |
| 可回收利用率 | Recyclability Rate | 整车材料可回收部分所占比例 |

## 4. 主流技术方案与取舍

车身方案的取舍集中在材料与连接两点，两者互相绑定。

| 方案 | 适用场景 | 代价 |
| --- | --- | --- |
| 低碳钢为主 | 经济型车、大批量 | 重量大，靠结构补刚度 |
| 高强钢与热成形钢 | 碰撞关键区、A/B 柱 | 成形窗口窄，模具与工艺复杂 |
| 铝合金车身 | 中高端电动车、轻量化 | 连接工艺全新，维修成本高 |
| 镁合金与复合材料 | 局部零件、试验性应用 | 供应链弱，耐蚀与连接难 |
| 传统点焊 | 钢制车身主线 | 热影响区大，铝钢混用不适用 |
| SPR 与 FDS 加结构胶 | 铝车身、多材料混合 | 设备投资高，工艺窗口需严格管控 |

悬架与车身的关系也影响结构方案。承载式车身（Unibody）把底盘功能并入车身，重量与刚度效率高，但安装点局部需要加强；非承载式（Body-on-Frame）把载荷交给车架，车身自由度大，代价是重量与高度。乘用车几乎全用承载式，硬派越野仍保留非承载结构。

内外饰的材料取舍更偏感知与法规。软质搪塑手感好但成本高，硬质注塑加纹理便宜但易反光；真皮透气但耐污差，人造革易清洁但气味与老化需要控制。真正的难点不是选材料，而是保证同一批、同一车型、不同供应商的件在色差、光泽、硬度上看起来是"一套"。

工艺选择同理。一模多腔能降本，但各腔的填充与收缩差异会放大尺寸与外观偏差；免喷涂材料省掉喷涂工序，代价是纹理质感与耐刮擦的把关更严，一旦出现流痕只能整件报废。这些取舍都要在方案阶段把总成本算全，而不是只比单件报价。

## 5. 关键交付物与评审要点

| 交付物 | 内容 | 评审要点 |
| --- | --- | --- |
| 主断面图 | 关键位置的钣金层叠与搭接关系 | 传力是否连续，密封与涂装是否可行 |
| DTS 图 | 全车间隙面差的目标与公差 | 是否与造型意图一致，是否可制造 |
| 钣金件图纸 | 材料、料厚、成形工艺、基准 | 基准是否统一，回弹补偿是否给出 |
| 焊接装配树 | 焊点数量、顺序、夹具定位 | 焊接可达性、变形控制 |
| 匹配报告 | 首件与检具测量数据 | 尺寸链是否闭合，超差是否有措施 |
| 内外饰感知清单 | 色差、光泽、纹理、气味目标 | 是否覆盖全部可见面与可触面 |

评审时有三个高频失分点。第一是基准混乱：设计基准、制造基准、测量基准不统一，导致同一处尺寸在三份报告里有三个值。第二是公差堆叠失控：单个零件都在公差内，装到一起却超差，因为没有做尺寸链分析。第三是只评审数模不评审工艺：数模上完美贴合，实际冲压回弹后需要强行装配，装完就是异响与缝隙。

## 6. 标准、法规与工具链

安全与碰撞：C-NCAP 与 C-IASI 的评价规程（版本年度更新，以官方发布为准）、GB 11551（正面碰撞乘员保护）、GB 20071（侧面碰撞）。门锁与车门保持：FMVSS 206、GB 15086。车内空气：GB/T 27630《乘用车内空气质量评价指南》。回收利用：GB/T 19515《道路车辆 可再利用率和可回收利用率计算方法》、欧盟 2000/53/EC（报废车辆指令）。腐蚀：GB/T 10125（人造气氛腐蚀试验，盐雾试验）。材料：VDA 239-100（冷成形用冷轧钢板供货技术条件）。

隐藏式门把手、电动门等新结构还牵涉断电应急开启与功能安全要求，需按 ISO 26262:2018 的思路评估失效后果，并核对最新版国标与准入要求。

工具链：造型与结构设计用 CATIA、NX、Alias；冲压成形仿真用 AutoForm、PAM-STAMP；碰撞与刚度用 LS-DYNA、PAM-CRASH；注塑用 Moldflow；尺寸链与公差分析用 3DCS、VSA；测量用三坐标与蓝光扫描。工具之间的数据接口比工具本身更值得关注，A 面到结构、结构到模具、模具到检具，任何一次转换都可能引入偏差。

## 7. 与其他领域的接口与常见冲突

**与造型的接口**：最经典的冲突。造型要特征线与曲率连续，工程要成形极限与脱模角（见[整车开发流程与项目管理](/note/vehicle-dev/)中的造型冻结约束）。有效做法是在造型阶段就引入可行性回检，把"这条棱线需要几序冲压、成本增加多少"提前摆到桌面上，而不是等冻结后再说做不到。

**与底盘的接口**：悬架与动力总成的安装点刚度直接影响操稳与 NVH（见[底盘系统](/note/chassis/)）。车身局部刚度不足，会让衬套隔振失效，路面冲击直接传进座舱。冲突在于加强结构要增重，解决办法是把加强集中在载荷路径上，而不是整车均匀加厚。

**与 EEA 的接口**：线束过孔、天线位置、传感器安装面、隐藏式门把手的执行器，都要在钣金上留位置（见 [EEA 学习笔记](/note/eea/)中的[线束、连接器与拓扑设计](/pages/4a9c2e7f1b6d0538/)）。常见冲突是后期加装传感器导致开孔位置与密封、防腐冲突，补救只能加胶堵或改模。

**与制造的接口**：焊装节拍与涂装通过性会反向约束设计。焊枪进不去的位置只能改点焊为铆接或加长电极，成本与节拍都会变；涂装电泳的排液孔没留好，会出现积液与流痕。

## 8. 常见坑与检查清单

- [ ] 主断面是否覆盖全部关键搭接，传力路径是否连续
- [ ] DTS 是否逐条与造型确认，公差是否经过尺寸链验证
- [ ] 冲压件是否做过成形仿真，回弹补偿是否写入模具设计
- [ ] 基准体系（设计、制造、测量）是否统一并写入图纸
- [ ] 焊枪与夹具的可达性是否在数模阶段验证
- [ ] 电泳排液、排气孔是否布置，是否存在积液风险
- [ ] 内外饰色差、光泽、纹理是否有跨供应商的统一标准
- [ ] 新结构（电动门、隐藏把手）是否做过断电与失效场景验证

## 9. 学习路径与资料

入门先建立"三层"认识：结构层（传力路径与刚度）、工艺层（冲压、焊接、涂装、总装）、感知层（缝隙、触感、气味、声音）。推荐从一张主断面图读起，把每一层钣金的作用讲清楚，比看十篇综述更有用。

进阶抓两条线。一条是尺寸工程：学会做尺寸链分析，理解公差如何在装配中累积，这是解决缝隙与异响的根本。另一条是材料与连接：把钢、铝、镁的成形与连接特性各做一次对比实验或仿真，你会明白为什么轻量化不是换材料那么简单。

资料优先级：国标与法规原文最先看，其次是 VDA 与 AIAG 的工艺指南，再次是材料供应商的技术手册（宝钢、诺贝丽斯等的公开资料质量很高），最后是行业会议案例。标准号与版本以官方最新发布为准。
