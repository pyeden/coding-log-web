# 整车集成与性能属性

一台车由一两万个零件组成，但用户感知到的只有几十个"属性"：起步有没有力、过减速带颠不颠、高速飘不飘、关门声厚不厚、夏天暴晒后多久能凉下来。整车集成要做的，是把这些模糊的体感翻译成可测量、可分解、可验证的指标，再让分散在各系统手里的设计动作收敛到同一组数值上。

## 1. 这个领域解决什么问题

属性（Attribute）是整车级的功能表现，它不属于任何一个零件，却由所有零件共同决定。整车集成的核心工作是三件事：定义属性目标、把目标分解到系统与零件、在冲突出现时做裁决。

边界必须讲清楚。集成不负责设计悬架连杆，也不负责写座舱代码；它负责说"这台车要以 60 km/h 通过某个粗糙路面时，方向盘振动不超过多少、车内噪声不超过多少分贝"，然后判断底盘方案与车身声学包加起来能不能满足。它也不做造型审美，但会否掉一个让风阻系数上涨 0.02 的造型细节。

这个岗位最难的地方在于：属性之间天然互相打架。要操稳就得把悬架调硬，调硬就牺牲平顺；要 NVH 就得加声学包，加包就增重增成本；要续航就得低风阻，低风阻往往要牺牲后排头部空间。集成的价值不是消除冲突，而是把冲突显式化，并在整车层面选出总代价最小的组合。

这件事听着抽象，落到会上就是排优先级。十几项属性不可能同时做到同级最优，必须交代清楚哪三项是这辆车的"胜负手"，其余项只要不落入竞品劣势区间就算达标。权重一旦确定，后续所有资源分配、方案取舍、甚至供应商谈判都有了依据。反过来，如果每项属性都要求"同级最好"，结果通常是每项都平庸，而且项目预算会先崩。

还有一层是时间维度。属性不是一次验收，而是贯穿整个生命周期：新车状态、磨合后、三万公里、六年老化，性能都会漂移。目标书里如果不写清"在哪个里程节点达标"，后期就会出现"新车合格、老车不合格"的争议，而这种争议往往在售后才爆发。

## 2. 在整车开发流程中的位置

上游是产品定义与竞品对标：这辆车卖给谁、和谁比、赢在哪几项。下游是各系统的详细设计与供应商选型。

| 环节 | 输入 | 输出 | 责任方 |
| --- | --- | --- | --- |
| 属性定义 | 产品定位、竞品实测数据、法规要求 | 属性清单与目标值 | 整车集成 |
| 目标分解 | 整车目标、系统能力边界 | 系统级与零件级指标 | 集成加各系统 |
| 方案验证 | 数模、仿真模型 | CAE（Computer-Aided Engineering）结果、方案对比 | 集成加 CAE |
| 样车验证 | 样车、试验场、台架 | 实测数据与问题清单 | 试验加集成 |
| 调校收敛 | 问题清单、主观评价 | 标定与设计变更 | 系统加集成 |
| 投产确认 | 量产状态样车 | 属性一致性报告 | 质量加集成 |

时间上有条铁律：属性目标必须在方案阶段冻结，否则后期只能靠"调"来救，而调校能补偿的余量通常只有一到两成。目标定错，后面所有努力都是在错误的方向上优化。

## 3. 核心概念与术语表

| 术语 | 英文全称 | 一句话解释 |
| --- | --- | --- |
| 属性 | Attribute | 用户可感知的整车级性能表现 |
| 目标分解 | Target Cascading | 把整车指标逐层拆到系统与零件 |
| 属性冲突矩阵 | Trade-off Matrix | 记录属性间相互影响的工具 |

| 噪声振动与声振粗糙度 | Noise, Vibration and Harshness (NVH) | 声音、振动与主观粗糙感的综合评价 |

| 目标成本 | Target Costing | 由售价倒推的允许成本 |

## 4. 主流技术方案与取舍

属性工程有三条常见路线，取舍在于"什么时候花多少钱买确定性"。

| 方案 | 适用场景 | 代价 |
| --- | --- | --- |
| 竞品反推加经验系数 | 改款车、成熟平台、时间紧 | 创新上限低，容易继承竞品缺陷 |
| 仿真驱动的前置优化 | 全新平台、新能源车型 | 建模与算力投入大，模型置信度需标定 |
| 台架加整车迭代调校 | 底盘、NVH、热管理 | 样车与试验场资源占用高，周期长 |
| 主观评价主导 | 感知质量、驾驶性 | 依赖评价员水平，难量化难复现 |

实际项目是四者叠加：先用竞品数据定基线，再用仿真做方案筛选，然后用台架与样车收敛，最后用主观评价验收。比例随项目成熟度变化——新平台仿真占比高，改款车主观评价占比高。

验证手段的选择也有取舍。CAE 便宜但置信度依赖模型标定，尤其碰撞与 NVH 的内饰件建模误差很大；台架可控但边界条件与实车不同；整车路试最真实但贵且受天气与场地限制；主观评价能捕捉仪器测不到的东西，却无法在供应商之间传递。成熟做法是建立"仿真—台架—整车"的相关性链条，用实测反标模型，让三者互为校验而不是互相替代。

组织形态同样有取舍。属性主导型（属性工程师有权否方案）收敛快但容易与系统部门对立；系统主导型（各系统自评）执行顺但整车容易失控；矩阵型最常见，成败取决于守门人是否有真实的预算与进度权力。挂名不管事的集成，等于没有集成。

## 5. 关键交付物与评审要点

| 交付物 | 内容 | 评审要点 |
| --- | --- | --- |
| 属性目标书 | 十几项属性的目标值、竞品值、权重 | 目标是否可达、是否与定位一致 |
| 属性分解表 | 系统级指标与责任人 | 分解是否闭合，余量分配是否合理 |
| 冲突矩阵 | 属性两两影响的方向与量级 | 关键冲突是否都有裁决记录 |
| 仿真报告 | 工况、模型、边界条件、结论 | 模型是否经过实测标定 |
| 试验报告 | 场地、天气、胎压、载荷、数据 | 边界条件是否可复现 |
| 主观评价表 | 评分项、权重、评价员 | 评价员是否受训、样本量是否足够 |

另一件常被跳过的事是数据与体感的对齐。仪器测出的分贝值、加速度均方根值，与人耳人身的感受并非线性对应，所以同一份报告里必须同时给出客观数据与主观评分，并说明两者出现分歧时的处理原则。实践中的经验是：客观数据用于判是否越线，主观评价用于判是否有高级感，两者都不能单独作为放行依据。

评审最该盯的是"余量"。每个系统都倾向于多要余量，整车总量就会崩。有效做法是把余量当成预算来管：整车留多少、系统分多少、谁批准超支，全部写进文件。另一个重点是边界条件，同一台车在满载与空载、冷胎与热胎、20 度与 35 度环境下的表现差异可能超过方案之间的差异，报告不写清边界，数据就没有比较意义。

## 6. 标准、法规与工具链

能耗与排放：GB/T 38146.1-2019（中国汽车行驶工况，CLTC）、GB 18352.6-2016（轻型汽车污染物排放限值，中国第六阶段）、UN GTR 15（WLTP，全球统一轻型车测试规程）。制动：GB 21670-2025《乘用车制动系统技术要求及试验方法》（2026-01-01 实施，代替 GB 21670-2008）。操稳试验：ISO 3888-2（双移线）、GB/T 6323（汽车操纵稳定性试验方法）。功能安全：ISO 26262:2018；网络安全：UN R155、UN R156 与 ISO/SAE 21434:2021。具体版本与实施日期以最新官方发布为准。

工具链按属性分工：动力性与经济性用 GT-SUITE、Simcenter Amesim、Simulink 做整车能量流仿真；操稳与平顺用 Adams/Car、CarSim、Simpack；空气动力学用 STAR-CCM+、PowerFLOW；NVH 用 VA One、Simcenter Testlab、HEAD acoustics；热管理用 KULI、Amesim、STAR-CCM+ 联合；试验数据管理用各自的数据平台并通过工况 ID 回链。工具不解决冲突，它只让冲突更早暴露。

## 7. 与其他领域的接口与常见冲突

**与底盘的接口**：操稳与平顺的经典对立。降低车身、加硬弹簧、增大防倾杆能提升转向响应，代价是冲击感与次级振动变差（见[底盘系统](/note/chassis/)）。裁决依据是产品定位：家用车偏平顺，性能车偏操稳。工程上常用可变阻尼或空气悬架做折中，代价是成本与复杂度。

**与车身的接口**：重量、刚度与声学包的三方拉扯。车身加厚加筋能提升刚度与 NVH，但增重直接吃掉能耗与操控（见[车身与内外饰](/note/body-interior/)）。有效做法是把刚度目标按"载荷路径关键区"分配，而不是全车身均匀加料。

**与 EEA 的接口**：功能越多，能耗与散热压力越大。座舱大屏、智驾域控、冰箱彩电都要电，配电与热管理必须提前算总账（见 [EEA 学习笔记](/note/eea/) 中的[电源与配电架构](/pages/1d7e4b9a6c2f8350/)）。常见冲突是"后期加功能"导致静态电流超标、蓄电池亏电，或域控降频影响体验。

**与流程的接口**：属性目标需要冻结时点，而市场与竞品在项目周期内会变（见[整车开发流程与项目管理](/note/vehicle-dev/)）。变更不可避免，但必须有"重开目标"的正式流程，而不是让目标在会议里被悄悄稀释。

## 8. 常见坑与检查清单

- [ ] 属性目标是否写明测试工况、载荷状态、环境条件与轮胎规格
- [ ] 每项目标是否只有一个责任系统，避免"共同负责"变成无人负责
- [ ] 冲突矩阵中的关键矛盾是否有书面裁决与补偿方案
- [ ] 仿真模型是否用同平台实测数据标定过，误差范围是否记录
- [ ] 余量预算是否集中管理，超支是否需要等量补偿
- [ ] 主观评价员是否受训、是否有跨车型一致性与重复性数据
- [ ] 样车状态（轮胎、胎压、四轮定位、载荷）是否与目标定义一致
- [ ] 量产一致性是否验证过，而不是只验证手工样车

## 9. 学习路径与资料

入门读三样：车辆动力学基础教材（操稳与平顺的物理直觉）、NVH 概论（噪声源、传递路径、控制手段）、以及一份完整的整车属性目标书样本（理解指标怎么写成可测的句子）。这三样凑齐，你才能听懂评审会上的争论在争什么。

进阶分两条线。一条是仿真：把 Adams/Car 或 CarSim 里的整车模型搭起来，做一次悬架硬点灵敏度分析，你会明白为什么调校是"牵一发动全身"。另一条是试验：跟一次试验场的操稳与平顺试验，看数据怎么采、边界怎么控、异常怎么复现。两条线交叉验证，才形成判断力。

资料优先级：ISO 与国标的试验方法条款最可靠，其次是主机厂公开的技术白皮书与 SAE 论文，再次是工具厂商的应用案例。标准号与版本以官方最新发布为准，本文数值仅作量级参考。
