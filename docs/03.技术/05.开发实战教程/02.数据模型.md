# 02. 数据模型

## 这一章解决什么

把“博客”翻译成数据库表，并想清楚表之间的关系。

## 模型清单

- `ArticleColumn`：栏目，文章的一对多归档。
- `Article`：文章主体。
- `ArticleLike`：用户和文章的唯一关联。
- `Comment`：评论，自关联做两级树。
- `Notification`：评论通知。
- `Profile`：用户扩展资料。

## 文章

```python
class Article(models.Model):
    author = models.ForeignKey(User, on_delete=models.CASCADE, related_name="articles")
    title = models.CharField(max_length=200)
    slug = models.SlugField(max_length=220, unique=True, blank=True)
    body = models.TextField()
    body_html = models.TextField(blank=True, default="")
    cover = models.ImageField(upload_to="covers/", blank=True, null=True)
    column = models.ForeignKey(ArticleColumn, on_delete=models.SET_NULL, null=True, blank=True)
    tags = TaggableManager(blank=True)
    total_views = models.PositiveIntegerField(default=0)
    likes = models.PositiveIntegerField(default=0)
    created = models.DateTimeField(auto_now_add=True)
    updated = models.DateTimeField(auto_now=True)
```

`body` 存 Markdown 源文，`body_html` 存渲染后的 HTML。这样列表和详情不用每次重新渲染，编辑时又能拿回源文。

`slug` 自动生成且唯一：

```python
def _unique_slug(self):
    base = slugify(self.title, allow_unicode=True)[:200] or "article"
    candidate = base
    index = 2
    while Article.objects.filter(slug=candidate).exclude(pk=self.pk).exists():
        candidate = f"{base}-{index}"
        index += 1
    return candidate
```

保存时同时刷新 `body_html`，保证详情页和编辑器预览一致。

## 点赞

```python
class ArticleLike(models.Model):
    article = models.ForeignKey(Article, on_delete=models.CASCADE, related_name="article_likes")
    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name="article_likes")
    class Meta:
        constraints = [models.UniqueConstraint(fields=["article", "user"], name="unique_article_like")]
```

不要只存一个 `likes` 整数。有关联表才能判断“这个人是否点过”，也才能保证重复请求不重复计数。

## 评论

```python
class Comment(models.Model):
    article = models.ForeignKey(Article, on_delete=models.CASCADE, related_name="comments")
    user = models.ForeignKey(User, on_delete=models.CASCADE, related_name="comments")
    body = models.TextField()
    parent = models.ForeignKey("self", on_delete=models.CASCADE, null=True, blank=True, related_name="replies")
    active = models.BooleanField(default=True)
    created = models.DateTimeField(auto_now_add=True)
```

只做两级：回复的回复归到根评论下。这样前端渲染简单，也不会出现无限缩进。

## 用户资料

`Profile` 与 `User` 一对一，用 `post_save` 信号自动创建：

```python
@receiver(post_save, sender=User)
def ensure_profile(sender, instance, created, **kwargs):
    Profile.objects.get_or_create(user=instance)
```
