# 06. 首页与文章列表

## 这一章解决什么

让读者一进来就能看到最近写了什么，并能从侧栏找到最热、栏目和标签。

## 数据请求

首页只请求一个接口：

```js
const data = await listArticles({ page, page_size: 6 })
```

响应是 `{count, next, previous, results}`。前端用 `count` 算总页数，不依赖 `next` 是否存在。

## 文章卡片

`ArticleCard` 负责一条文章的展示：

- 有封面时左侧缩略图，没有封面时单列。
- 元信息：栏目、日期、浏览量。
- 标题链接到 `/article/:slug`。
- 摘要两行截断。
- 标签胶囊。
- 底部作者、评论数、点赞数。

封面用 `mediaUrl()` 处理相对/绝对路径。生产环境后端返回带 `/djangovueblog/media/` 的绝对 URL，前端不再拼前缀。

## 列表容器

`ArticleFeed` 管四件事：请求、分页、加载态、空状态。它接收 `filters`，搜索页、栏目页、标签页都复用它：

```vue
<ArticleFeed :title="..." :filters="{ search: q }" />
```

`filters` 变化时重置到第一页；翻页只改 `page`。请求失败显示错误和“重试”，不把空白页丢给读者。

## 侧栏

`SidebarPanel` 包含：

- 搜索框：回车跳 `/search?q=`。
- 最热文章：`/api/articles/hot/`，显示前 5。
- 栏目：标题和文章数。
- 标签云：按名称链接到 `/tag/:slug`。
- 关于：一句话说明这个站。

侧栏自己加载元数据，不依赖首页传参；这样详情页也能复用。

## 分页

`PaginationBar` 只做三件事：上一页、页码、下一页。页码多时用省略号，不渲染几十个按钮。当前页用深色底，禁用态降低透明度。

## 加载与空状态

- 加载中：三条骨架卡片，保持布局高度，避免跳动。
- 空结果：一句话 + 图标，告诉读者“换个关键词”。
- 错误：显示具体错误和重试按钮，不要只写“出错了”。

## 验证

- 首页 6 条一页，翻页正常。
- 搜索 `Django` 有结果，搜索乱码显示空状态。
- 侧栏最热、栏目、标签都能点。
- 窄屏侧栏在列表下方。

## 小结

首页是阅读动线的起点。卡片信息足够判断“要不要点”，侧栏提供第二条路径。下一章写详情页。
