# 14. 常见问题

## 中文标题打不开文章

Django 的 `<slug:slug>` 只匹配 ASCII。中文标题生成的 slug 含中文，路由匹配不到。解决：

- `ArticleViewSet` 设 `lookup_value_regex = r"[^/.]+"`
- 评论路由用 `<str:slug>`
- 前端跳转用 `encodeURIComponent(slug)`

## 登录后写操作还是 403

Django `login()` 会轮换 CSRF token。登录成功后重新 `GET /api/auth/csrf/`，读新的 `csrftoken` cookie，再带 `X-CSRFToken` 发请求。

## pip 安装依赖报 ProxyError

系统代理可能指向已经退出的端口。强制直连：

```bash
export no_proxy='*' NO_PROXY='*' HTTP_PROXY='' HTTPS_PROXY='' ALL_PROXY=''
pip install -i https://mirrors.aliyun.com/pypi/simple/ -r requirements.txt
```

## 刷新 /djangovueblog/article/xxx 变成 404

SPA 的 history 路由需要 nginx 回退：

```nginx
location /djangovueblog/ {
    root /Users/mac/djangovueblog-releases/current/frontend;
    try_files $uri $uri/ /djangovueblog/index.html;
}
```

## 封面/头像 URL 少了 /djangovueblog

生产环境设 `DJANGO_MEDIA_URL=/djangovueblog/media/`，否则 `request.build_absolute_uri()` 会生成不带子路径的 URL。nginx 再用 alias 指到数据目录。

## 改了 nginx 配置还是 404

`nginx -t` 只检查语法，不会让配置生效。需要：

```bash
sudo /usr/local/opt/nginx/bin/nginx -t
sudo /usr/local/opt/nginx/bin/nginx -s reload
```

## 演示账号是什么

`demo / demo12345`。管理员 `admin`，密码只在部署机的数据目录，不写入仓库。

## 为什么没有第三方登录

需要 OAuth App 的 Client ID/Secret 和回调地址。没有凭据时强行接入只会留下一个不可用的按钮；等有真实需求再接入。

## 文章列表响应为什么带正文

列表和详情共用 `ArticleSerializer`，列表也带 `body/body_html`，payload 偏重。文章多时可以拆 List/Detail 序列化器，列表只返回摘要。

## 为什么点赞要求登录

登录后可以靠 `ArticleLike` 唯一约束做幂等和审计。游客点赞只能存浏览器，换设备就能重复点，数据不可信。
