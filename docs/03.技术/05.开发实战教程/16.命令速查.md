# 附录 B：命令速查

## 后端

```bash
cd ~/work/django-vue-blog/backend
source .venv/bin/activate
python manage.py runserver 127.0.0.1:8000
python manage.py migrate
python manage.py makemigrations
python manage.py test
python manage.py seed_demo
python manage.py createsuperuser
```

## 前端

```bash
cd ~/work/django-vue-blog/frontend
npm install
npm run dev
npm run build
```

## 检查数据库

```bash
cd ~/work/django-vue-blog/backend
source .venv/bin/activate
python manage.py shell -c "from blog.models import Article; print(Article.objects.count())"
```

## 本地 API 冒烟

```bash

```

## 查看 gunicorn 健康

```bash
curl --noproxy '*' http://127.0.0.1:8899/api/health/
```

## nginx 检查与重载

```bash
sudo /usr/local/opt/nginx/bin/nginx -t
sudo /usr/local/opt/nginx/bin/nginx -s reload
```
