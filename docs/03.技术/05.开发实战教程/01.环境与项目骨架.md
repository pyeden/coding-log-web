# 01. 环境与项目骨架

## 这一章解决什么

把 macOS 上的工具链固定下来，建出两个可以独立启动的工程：`backend/` 和 `frontend/`。

## 工具链

我用的是：

| 项 | 版本 |
| --- | --- |
| macOS | 15.x |
| Python | 3.12（Homebrew） |
| Django | 4.2 LTS |
| Node | 24.x |
| 数据库 | SQLite |

Python 不要用系统自带的旧版本。Homebrew 安装后确认路径：

```bash
brew install python@3.12
/opt/homebrew/bin/python3.12 --version
```

## 后端骨架

```bash
mkdir -p ~/work/django-vue-blog/{backend,frontend,docs,deploy}
cd ~/work/django-vue-blog/backend
/opt/homebrew/bin/python3.12 -m venv .venv
source .venv/bin/activate
pip install "Django==4.2.*" djangorestframework django-taggit django-filter Pillow markdown bleach django-cors-headers gunicorn
django-admin startproject config .
python manage.py startapp accounts
python manage.py startapp blog
python manage.py startapp comments
python manage.py startapp notices
```

项目包叫 `config`，四个 app 按领域拆：账号、文章、评论、通知。不要把所有模型塞进一个 app，后面迁移和测试都会难受。

在 `config/settings.py` 注册：

```python
INSTALLED_APPS = [
    # ...
    "rest_framework", "corsheaders", "taggit", "django_filters",
    "accounts", "blog", "comments", "notices",
]
```

## 前端骨架

```bash
cd ../frontend
npm create vite@latest . -- --template vue
npm install
npm install axios pinia vue-router bootstrap bootstrap-icons marked dompurify highlight.js
npm run dev
```

开发时 Vite 跑在 5173，Django 跑在 8000。`vite.config.js` 把 `/api` 代理到 8000，前端代码里只写 `/api`，不写完整域名。

## 环境变量

后端的关键配置从环境变量读：`DJANGO_SECRET_KEY`、`DJANGO_DEBUG`、`DJANGO_ALLOWED_HOSTS`、`DJANGO_CSRF_TRUSTED_ORIGINS`、`DJANGO_DB_PATH`。开发环境可以不设，生产必须设。

## 跑起来

两个终端：

```bash
cd backend && source .venv/bin/activate && python manage.py runserver 127.0.0.1:8000
cd frontend && npm run dev
```

打开 <http://127.0.0.1:5173>，看到 Vite 的默认页就说明骨架通了。

## 坑

- `source .venv/bin/activate` 必须在 `backend/` 下执行，路径别写错。
- 8000 端口被占用时换 8001，同时改 Vite 代理。
- 不要把项目放在 iCloud 同步目录，文件监听会抽风。
