# 07. 文章详情与 Markdown

## 这一章解决什么

把 Markdown 安全地渲染成 HTML，并给长文一个可用的目录。

## 渲染管线

后端 `blog/utils.py` 做三件事：

1. `markdown` 转换，启用 `fenced_code`、`codehilite`、`toc`、`tables`。
2. `bleach.clean` 白名单清洗。
3. 提取 `toc_tokens` 为 `{level, text, anchor}`。

```python
html = markdown.markdown(text, extensions=MD_EXTENSIONS, extension_configs=MD_EXTENSION_CONFIGS)
safe = bleach.clean(html, tags=ALLOWED_TAGS, attributes=ALLOWED_ATTRIBUTES, protocols=ALLOWED_PROTOCOLS, strip=True)
```

白名单保留标题、段落、列表、表格、代码、图片和链接；`class`/`id` 保留给代码高亮和目录锚点。协议只允许 `http/https/mailto`。

## 详情页

`ArticleDetailView` 请求 `/api/articles/:slug/`，拿到：

- `body_html`：直接渲染，不再在前端跑 Markdown。
- `toc`：目录。
- `liked`、`likes`、`comment_count`、作者信息。

正文用 `MarkdownBody` 渲染，内部再做一次 DOMPurify，双保险。代码块用深色背景 + Pygments token 颜色，保证可读。

## 目录

`TocRail` 接收 `toc`，点击滚动到对应 heading。滚动高亮用 `IntersectionObserver`，观察 `.prose h1–h6[id]`。目录在窄屏隐藏，正文仍然完整。

中文标题的 anchor 由 Python-Markdown 生成，可能是 `_1`、`_2`，不是中文拼音；前端不要自己猜，直接用后端返回的 `anchor`。

## 评论与操作区

详情页底部是点赞、编辑/删除（作者或 staff）、评论表单和评论树。未登录时显示“登录后评论”，不隐藏评论区。

## 浏览量

详情 GET 时用 `F("total_views") + 1` 原子自增，再把实例上的值加 1 返回。不要先读再写，否则并发会丢计数。这个计数按请求累加，不做用户去重；个人博客够用。

## 验证

- Markdown 标题、列表、表格、代码块正常。
- `<script>` 被清洗。
- 目录点击能滚动，滚动时高亮跟随。
- 刷新深层链接不 404（部署章节处理）。

## 小结

详情页是读者停留最久的地方。渲染安全和目录体验，比花哨的动效重要。下一章写写作端。
