# 附录 A：术语表

按第一次出现的顺序整理。解释尽量用大白话，不追求学术定义。

## 终端 / Shell

一个用文字和电脑对话的窗口。你输入命令，电脑执行。macOS 自带“终端”应用。

## 目录

就是文件夹。`cd` 进入目录，`ls` 列出内容，`pwd` 显示当前位置。

## 虚拟环境（venv）

给一个项目单独准备的 Python 环境。不同项目可以装不同版本的库，互不打架。激活后命令行前面会出现 `(.venv)`。

## 依赖

项目运行需要的第三方库，比如 Django、DRF、Pillow。`requirements.txt` 记录它们的版本。

## Django

用 Python 写网站的后端框架。它自带用户、权限、后台、数据库操作和路由。

## App

Django 里的功能模块。这个项目有 `accounts`（账号）、`blog`（文章）、`comments`（评论）、`notices`（通知）。

## ORM

把 Python 类映射成数据库表的工具。你写 `Article` 类，Django 帮你建表、查询、更新，不用手写 SQL。

## Model

Django 里的数据模型类，对应一张数据库表。字段就是表的列。

## Migration（迁移）

把 Model 的变化同步到数据库的操作。`makemigrations` 生成迁移文件，`migrate` 执行。

## API

后端提供给前端调用的接口。前端发请求，后端返回数据，通常用 JSON。

## JSON

一种文本数据格式，长这样：`{"title": "标题", "likes": 3}`。前端和后端都用它传数据。

## 序列化器（Serializer）

把 Model 对象转换成 JSON，或把前端传来的 JSON 校验后写进 Model。DRF 的核心工具。

## DRF

Django REST Framework，帮 Django 快速写 JSON API 的库。

## CSRF

跨站请求伪造防护。简单说：写请求必须带一个后端发的令牌，防止别的网站冒用你的登录状态。

## Session

后端记住“你是谁”的方式。登录后后端给浏览器一个 cookie，之后的请求带着它。

## SPA

单页应用。页面切换由前端路由完成，不整页刷新。这个项目的前端就是 SPA。

## 组件（Component）

Vue 里可复用的一块界面，比如文章卡片、评论节点。组件可以接收数据、发出事件。

## 路由（Router）

决定“哪个网址显示哪个页面”。`/article/:slug` 里的 `:slug` 是参数。

## Pinia

Vue 的状态管理库。把“当前用户、通知、栏目”等共享数据放在 store 里，多个页面都能读。

## Markdown

一种轻量写作格式，用 `#` 表示标题、`**` 表示粗体、``` 包代码块。写起来比 HTML 简单。

## XSS

跨站脚本攻击。用户输入里如果带 `<script>`，直接显示就可能被执行。所以要清洗 HTML。

## gunicorn

生产环境运行 Django 的服务器。开发用的 `runserver` 不适合上线。

## nginx

反向代理和静态文件服务器。它把 `/api/` 转发给 gunicorn，把图片、JS、CSS 直接返回。

## 反向代理

nginx 收到请求后，转给后面的程序（gunicorn），再把结果返回给浏览器。

## launchd

macOS 的服务管理工具。登录后自动启动 gunicorn，挂了自动拉起。

## 环境变量

不在代码里写死的配置，比如数据库路径、密钥、域名。用 `export` 设置，程序运行时读取。

## 子路径

网站挂在域名下的一个目录，比如 `https://example.com/blog/`。前端 `base`、API 前缀、nginx location 都要对应。
