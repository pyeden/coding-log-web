# Hello-Agents：从零开始构建智能体

> **学习心得**：读完这 16 章，我最大的变化不是记住了多少概念，而是能判断一个 Agent 系统为什么这样设计、瓶颈可能在哪里。这份笔记按学习路径重新组织，希望让你少走一些我走过的弯路。


> 一份系统化的智能体学习笔记：从核心概念、经典范式，到框架实现、通信协议与多智能体实战。

::: tip 关于这份笔记
内容整理自开源教程 [Hello-Agents](https://github.com/datawhalechina/Hello-Agents)，并结合本站排版做了结构化重排。既可以按章节顺序系统学习，也可以作为案头手册按需查阅。
:::

## 这本书讲什么

Hello-Agents 试图回答三个问题：

1. **智能体是什么**：从感知—决策—行动的闭环出发，理解智能体的构成与运行原理。
2. **如何构建智能体**：从 ReAct 等经典范式，到低代码平台、开发框架，再到从零实现一个 Agent 框架。
3. **如何做得更好**：记忆与检索、上下文工程、通信协议、强化学习训练与性能评估，最终落到三个完整实战项目。

## 适合谁读

- 想系统入门智能体，但被零散资料劝退的开发者；
- 有 Python 基础，希望理解 Agent 内部机制的工程师；
- 正在做 RAG、工作流、多智能体应用，需要一套完整参考架构的实践者；
- 准备面试或技术分享，需要快速检索关键概念的人。

## 阅读建议

- **先读第 1、4、7 章**：分别建立概念框架、理解经典范式、看清一个 Agent 框架的最小实现。
- **代码不要只看**：每章的示例建议在本地跑通，尤其是第 4、7、8 章的骨架代码。
- **第 10–12 章可以按需跳读**：协议、强化学习和评估更偏工程与研究，遇到项目需求时再回头精读。
- **第 13–16 章按项目读**：先看需求与架构，再对照代码理解每个模块的职责。
